# 03 掉落、装备与经济系统

## 1. 系统定位

掉落和装备系统负责制造“刷宝爽感”和“多局追求”。玩家每局都应该有可见收益：小到金币材料，大到蓝紫装备、图纸和 Boss 材料。

第一阶段目标不是做完整经济，而是建立最小可循环的收益链：

```text
怪物死亡
  -> 生成掉落
  -> 玩家拾取为未结算物资
  -> 撤离后入库
  -> 消耗材料强化
  -> 下一局清怪更快
```

## 2. 掉落体验目标

- 普通怪频繁给反馈，但不大量产出高价值装备。
- 精英怪必须明显比普通怪更值得打。
- Boss 掉落必须让玩家产生“这把要撤”的情绪。
- 掉落品质通过颜色、光柱、音效和结算展示体现。
- 高价值收益优先使用碎片、图纸、未鉴定装备，避免 3-5 局毕业。

## 3. 装备品质

| 品质 | 颜色 | 首版定位 | 掉落来源 |
| --- | --- | --- | --- |
| 普通 | 白 | 初始和过渡 | 普通怪、箱子 |
| 精良 | 绿 | 第一阶段主力成长 | 普通怪、强化怪 |
| 稀有 | 蓝 | 有 1 条词条 | 强化怪、精英怪 |
| 史诗 | 紫 | 有 2 条词条 | 精英怪、Boss |
| 传说 | 橙 | 特殊效果或 3 条词条 | Boss 小概率 |
| 神话 | 红 | 赛季终局 | 第一阶段不做 |

第一阶段建议只实装白、绿、蓝、紫、橙五档，其中橙装可先作为图纸或材料，不一定直接掉完整装备。

## 4. 装备类型

| 类型 | 第一阶段是否做 | 说明 |
| --- | --- | --- |
| 枪械 | 必做 | 决定玩家主要输出 |
| 头盔/护甲 | 可做简化 | 提供生命、防御或减伤 |
| 战术背包 | 可做简化 | 提供背包容量 |
| 饰品 | 暂缓 | 词条复杂度较高 |
| 消耗品 | 必做 | 药品、弹药、封存芯片占位 |
| 材料 | 必做 | 强化石、晶核、Boss 核心 |
| 图纸 | P1 | 提供长期目标 |

## 5. 首版词条

第一阶段先做少量清晰词条，避免调参爆炸。

| 词条 | 效果 | 首版用途 |
| --- | --- | --- |
| 猎魔 | 对普通怪伤害提升 | 提高清怪效率 |
| 首领杀手 | 对 Boss 伤害提升 | 提高 Boss 目标价值 |
| 破甲 | 对护甲怪伤害提升 | 克制重甲矿奴 |
| 快填 | 换弹速度提升 | 改善手感 |
| 稳定 | 降低后坐力或扩散 | 改善枪械体验 |
| 嗜血 | 击杀怪物回复少量生命 | 支撑连续刷怪 |
| 幸运 | 小幅提升材料掉落权重 | 长期刷宝追求 |
| 扩容 | 弹匣容量提升 | 提升持续输出 |

第一阶段只需要实现 3-4 个：猎魔、快填、稳定、首领杀手。

## 6. 掉落来源设计

| 来源 | 掉落内容 | 频率 | 设计目的 |
| --- | --- | --- | --- |
| 普通怪 | 金币、弹药、白绿装、基础材料 | 高频 | 保证击杀反馈 |
| 废土枪兵 | 弹药、枪械配件、绿装 | 中高 | 强化射击主题 |
| 爆裂虫 | 晶核碎片、强化材料 | 中 | 提供高威胁补偿 |
| 精英怪 | 蓝装、紫装机会、强化石、图纸碎片 | 低 | 单局小目标 |
| Boss | 紫装、橙装机会、Boss 材料、稀有图纸 | 单局 1 次 | 单局高潮 |
| 物资箱 | 药品、弹药、金币、材料 | 中 | 支撑探索路线 |

## 7. 掉落概率草案

| 来源 | 白 | 绿 | 蓝 | 紫 | 橙 |
| --- | --- | --- | --- | --- | --- |
| 普通怪 | 60% | 30% | 9% | 1% | 0% |
| 强化怪 | 30% | 40% | 25% | 5% | 0% |
| 精英怪 | 10% | 30% | 45% | 14% | 1% |
| Boss | 0% | 10% | 45% | 35% | 10% |

这些概率是手感草案。实际要结合每局怪物数量、撤离率、死亡损失和强化消耗一起调。

### 7.1 M1 单局产出预算

M1 先用预算约束掉落概率，避免只看单个怪物的掉率导致经济失真。

| 项目 | 起始目标 |
| --- | --- |
| 普通怪数量 | 单局 20-30 只 |
| 精英数量 | 单局 1 只 |
| Boss 占位目标 | 0-1 只，掉 Boss 材料，不直接掉完整橙装 |
| 有效掉落次数 | 单局 3-5 次 |
| 普通撤离带出 | 金币、基础强化石、1-2 件绿/蓝物资 |
| 精英撤离带出 | 额外蓝装或紫色材料机会 |
| Boss 占位撤离带出 | Boss 材料、紫色材料机会、橙色图纸碎片小概率 |
| 死亡失败 | 保险箱保留；普通材料损失 50%；蓝色以上未保护物资先全部损失 |

## 8. 未结算与入库

### 8.1 未结算状态

局内获得的高价值物资默认未结算：

- 未撤离死亡：按规则损失。
- 放入保险箱：死亡后保留。
- 成功撤离：进入仓库或变为已结算。

### 8.2 入库规则

| 物品类型 | 撤离成功 | 死亡失败 | 保险箱 |
| --- | --- | --- | --- |
| 金币 | 入库 | 损失部分 | 可保护少量或不占格，待定 |
| 基础材料 | 入库 | 损失 50% | 可保护 |
| 蓝紫装备 | 入库 | 掉落或损失 | 可保护部分 |
| Boss 核心 | 入库 | 高概率损失 | 第一阶段建议不可保险 |
| 已穿戴装备 | 保留 | 保留 | 不需要保险 |

## 9. 强化与经济消耗

第一阶段只做最小强化：

| 强化等级 | 消耗 | 效果 | 失败规则 |
| --- | --- | --- | --- |
| +1 到 +3 | 金币 + 基础强化石 | 每级约 8%-10% 伤害提升 | 100% 成功 |
| +4 到 +5 | 金币 + 高级强化石 | 每级约 10%-12% 伤害提升 | 可先 100% 成功 |
| +6 以后 | 暂缓 | 后续版本 | 后续再设计 |

第一阶段不要做降级、碎装、复杂洗练。先验证玩家是否愿意为“下一局更快清怪”消耗材料。

### 9.1 M1 强化验收

| 指标 | 起始目标 |
| --- | --- |
| 行尸 TTK | +0 步枪约 1.0-1.5 秒，+3 后降低约 20%-30% |
| 枪兵 TTK | +0 步枪约 2.0-3.0 秒，要求玩家优先找掩体或转火 |
| 精英 TTK | 单人约 60-90 秒，小队约 30-60 秒 |
| Boss 占位 TTK | 单人约 90-150 秒，小队约 60-90 秒 |
| 3 局成长 | 至少完成 1-2 次强化 |

## 10. 第一阶段要完成的功能

| 优先级 | 功能 | 交付标准 |
| --- | --- | --- |
| P0 | 掉落表 | 普通怪、精英怪、Boss 至少各 1 张表 |
| P0 | 掉落实体 | 怪物死亡后生成可拾取物 |
| P0 | 品质表现 | 白绿蓝紫橙至少颜色不同 |
| P0 | 临时背包 | 拾取物进入本局未结算列表 |
| P0 | 结算入库 | 撤离后物品进入仓库或已结算列表 |
| P0 | 死亡损失 | 未结算物资按规则损失 |
| P0 | 基础材料 | 金币、强化石、Boss 材料 3 类资源 |
| P1 | 基础强化 | 消耗金币和强化石提升武器伤害 |
| P1 | 3-4 个词条 | 猎魔、快填、稳定、首领杀手 |
| P1 | 未鉴定装备 | 撤离后开奖，增强结算期待 |

## 11. 开工顺序

1. 做掉落表结构：来源、物品 ID、数量、权重、品质。
2. 接普通怪死亡掉落。
3. 接拾取进入未结算背包。
4. 接撤离入库和死亡损失。
5. 加品质颜色和结算展示。
6. 加精英/Boss 掉落表。
7. 加基础强化消耗。
8. 再做词条和未鉴定装备。

## 12. 验收标准

- 普通玩家一局内至少获得 3-5 次有效掉落反馈。
- 击杀精英后收益明显高于普通怪。
- Boss 掉落能让玩家想立刻撤离。
- 强化材料至少支撑 3-5 局的消耗目标。
- +3 强化后普通区清怪时间下降 20% 以上。
- 玩家能理解哪些物品是未结算，哪些已经入库。

## 13. M2+ 扩展方向

M1 只验证基础闭环。完整装备成长体系（+6~+15 强化、词条 Tier、套装、属性数值曲线）见 [07_射击休闲化与数值深化设计.md](07_射击休闲化与数值深化设计.md)。

---

## 14. 主要风险

- 橙装太早泛滥：第一阶段橙色可以更多表现为图纸或材料。
- 掉落太碎：材料要合并成少数几类，不要一开始做几十种。
- 词条太多：先做能改变体验的 3-4 个。
- 经济没有消耗口：强化必须第一阶段接入，否则材料没有意义。
- 未结算状态技术风险高：如果物品实例状态难做，就用本局收益表模拟。
