## 第一部分：射击休闲化设计

### 1. 核心原则

传奇的本质不是"操作难"，而是"决策对"——装备穿对了、Build 配对了，站在那里打就行。射击版同理：

> **玩家的爽感来源应该是"我伤害数字够不够大"，而不是"我枪法够不够好"。**

### 2. 三层"去硬核化"设计

#### 第一层：瞄打分离

| 机制 | 参数方向 | 目的 |
|------|---------|------|
| 辅助瞄准吸附 | 准星靠近敌人 15-20° 扇形自动吸附 | 降低跟枪门槛 |
| 腰射为主 | 腰射精度设为 70-80%，开镜只是"精度加成"（+20-30%） | 不强迫开镜 |
| 爆头非必须 | 爆头伤害仅 1.3-1.5 倍（传统 FPS 是 2-3 倍） | 打身体就够通关 |
| 弱点扩大化 | 精英怪弱点区域设为身体 30-40% 面积，而非小点 | 降低瞄准精度要求 |
| 子弹磁力 | PVE 中子弹对怪物有少量追踪修正（命中判定框扩大 10-15%） | 让"差不多瞄准"也能命中 |

**注意**：PVP 中以上辅助全部关闭或大幅衰减，保证竞技公平。

#### 第二层：技能和道具替代枪法

传奇有法师雷电术、道士火符——不需要瞄准。射击版提供等价替代：

| 技能类型 | 示例 | 操作要求 | 适用场景 |
|---------|------|---------|---------|
| 自动追踪弹 | 制导火箭、追踪手雷 | 锁定后自动命中，无需瞄准 | 手残玩家打 Boss |
| AOE 范围伤害 | 火箭筒、冲击波、燃烧弹 | 大致方向即可，爆炸半径覆盖 | 清怪群 |
| 召唤物/无人机 | 自动炮台、攻击无人机 | 放置后自动攻击，玩家只管走位 | 挂机式刷怪 |
| 技能大招 | 全屏闪电、弹幕风暴 | 冷却好了按一下，大范围清场 | 解围/BOSS Rush |

M1 阶段至少提供 1 个 AOE 技能（手雷强化版）和 1 个追踪类技能。

#### 第三层：敌人设计降低操作压力

传奇的怪是"站桩肉盾"——走得慢、血厚、攻击模式简单。射击版继承这个思路：

| 设计原则 | 具体做法 |
|---------|---------|
| 怪物移速慢 | 普通怪移速为玩家移速的 50-60%，精英怪 40-50% |
| 弹幕稀疏 | 远程怪射击间隔 2-3 秒，弹速中等，不是弹幕游戏 |
| 攻击预警明显 | 地面红圈持续 1.5-2 秒，前摇动作 0.8-1.2 秒 |
| 近战怪为主 | 70% 怪物是近战，远程怪少且伤害低（约为近战 60%） |
| 核心挑战是 DPS | 玩家焦虑的是"我伤害够不够"而不是"我能不能躲开" |

### 3. 辅助瞄准分级设计（M2 扩展）

M1 先用一套统一的辅助瞄准参数。后续可按难度分级：

| 难度 | 吸附范围 | 子弹磁力 | 爆头倍率 | 说明 |
|------|---------|---------|---------|------|
| 新手 | 25° | 20% | 1.3x | 打哪都中，爽就完了 |
| 普通 | 18° | 10% | 1.4x | 有操作感但门槛低 |
| 困难 | 12° | 5% | 1.5x | 需要一定枪法 |
| 噩梦 | 8° | 0% | 1.6x | 接近正常射击游戏 |
| 地狱 | 5° | 0% | 1.8x | 硬核玩家挑战 |

### 4. 伤害数字反馈

传奇最核心的爽感之一：满屏跳伤害数字。射击版必须做好：

| 元素 | 设计 |
|------|------|
| 普通伤害 | 白色数字，小号字体，快速上飘消失 |
| 暴击伤害 | 黄色数字，大号字体，带震动微反馈 |
| 弱点伤害 | 橙色数字，带破碎特效 |
| 击杀反馈 | 红色数字 + 击杀音效 + 击杀图标 |
| 稀有掉落提示 | 全屏光柱 + 品质颜色 + 特殊音效 + 物品名称飘字 |
| 伤害统计 | 结算界面显示"本局总伤害 / DPS / 最高单发伤害" |

## 第二部分：装备成长完整路线

> 当前 03 号文档覆盖了 M1 的 +1~+5 简化强化。以下是 M2+ 的完整成长体系设计。

### 1. 装备槽位总览

```
武器槽：主武器 + 副武器 + 近战武器
防具槽：头盔 + 护甲 + 护腿 + 战术背包
饰品槽：戒指×2 + 项链 + 徽章
特殊槽：技能模块 / 无人机模块
```

M1 只做主武器 + 简化头盔/护甲。M2 逐步解锁更多槽位。

### 2. 四层成长体系

#### 第一层：稀有度（颜色品质）

| 品质 | 颜色 | 基础属性倍率 | 词条数量 | 掉落来源 | M1 |
|------|------|------------|---------|---------|-----|
| 普通 | 白 | 1.0x | 0 | 普通怪、箱子 | ✅ |
| 精良 | 绿 | 1.3x | 0 | 普通怪、强化怪 | ✅ |
| 稀有 | 蓝 | 1.7x | 1 | 强化怪、精英怪 | ✅ |
| 史诗 | 紫 | 2.2x | 2 | 精英怪、Boss | ✅ |
| 传说 | 橙 | 2.8x | 3（含 1 条特效词条） | Boss、世界 Boss | M2 |
| 神话 | 红 | 3.5x | 4（含 2 条特效词条） | 赛季终局活动 | M3 |

#### 第二层：随机词条

每件装备掉落时随机附带词条。词条分三类：

**A. 攻击向词条**

| 词条 | 效果 | 数值范围 |
|------|------|---------|
| 猎魔 | 对普通/强化怪伤害 +N% | 5%-15% |
| 首领杀手 | 对 Boss/精英伤害 +N% | 8%-20% |
| 暴击率 | 暴击概率 +N% | 3%-10% |
| 暴击伤害 | 暴击伤害倍率 +N% | 10%-30% |
| 射速 | 射击速度 +N% | 5%-15% |
| 破甲 | 无视目标 N% 护甲 | 5%-20% |
| 元素强化 | 火焰/电击/冰冻伤害 +N% | 10%-25% |

**B. 防御向词条**

| 词条 | 效果 | 数值范围 |
|------|------|---------|
| 最大生命 | 生命值 +N% | 5%-15% |
| 护盾 | 额外护盾 +N 点 | 100-500 |
| 减伤 | 受到伤害 -N% | 2%-8% |
| 回血 | 每秒恢复 N 点生命 | 10-50 |
| 抗性 | 元素伤害减免 +N% | 5%-15% |

**C. 功能向词条**

| 词条 | 效果 | 数值范围 |
|------|------|---------|
| 快填 | 换弹速度 +N% | 10%-30% |
| 稳定 | 后坐力/扩散 -N% | 8%-25% |
| 扩容 | 弹匣容量 +N% | 10%-30% |
| 移速 | 移动速度 +N% | 3%-10% |
| 拾取范围 | 物品拾取范围 +N% | 20%-50% |
| 幸运 | 稀有掉落权重 +N% | 5%-20% |

**D. 稀有特效词条（仅橙/红装）**

| 词条 | 效果 |
|------|------|
| 嗜血 | 击杀怪物回复最大生命 5% |
| 连锁 | 击杀目标后子弹弹射到附近敌人（50% 伤害） |
| 斩杀 | 对 20% 血量以下目标伤害 +50% |
| 龙息 | 攻击 5% 概率触发范围火焰伤害（200% 武器伤害） |

| 雷击 | 击杀目标后对周围敌人释放闪电（150% 武器伤害） |

**词条数值 Tier 分级**（同一条词条的数值波动）：

| Tier | 数值范围 | 出现概率权重 |
|------|---------|------------|
| T1（低） | 下限 | 55% |
| T2（中） | 中值 | 30% |
| T3（高） | 接近上限 | 12% |
| T4（完美） | 上限 | 3% |

#### 第三层：强化（+1 到 +15）

M1 只做到 +5（100% 成功），M2 起扩展完整强化链：

| 阶段 | 等级 | 每级属性提升 | 材料消耗 | 成功率 | 失败惩罚 |
|------|------|------------|---------|--------|---------|
| 安全期 | +1 ~ +5 | 8% | 金币 + 基础强化石 | 100% | 无 |
| 成长期 | +6 ~ +8 | 10% | 金币 + 高级强化石 | 80% → 60% | 失败不掉级，消耗材料 |
| 危险期 | +9 ~ +12 | 12% | 金币 + 高级强化石 + 晶核 | 50% → 35% | 失败掉 1 级 |
| 冲刺期 | +13 ~ +15 | 15% | 金币 + 晶核 + Boss 核心 | 25% → 15% | 失败掉回 +10 |

**强化保护机制（商业化点）**：
- 强化保护符：单次失败不掉级（商城/活动获取，限量）
- 强化幸运石：单次成功率 +15%（稀有掉落/商城）
- 祝福强化：消耗额外材料保证 100% 成功（材料为普通 3 倍）

**强化外观反馈**：
- +7：武器外观微光
- +10：武器外观明显光效
- +13：武器发光 + 环绕粒子
- +15：武器流光溢彩 + 地面光晕 + 全服公告

| 套装规模 | 激活效果 | 设计意图 |
|---------|---------|---------|
| 2 件 | 小数值加成 | 容易凑齐，让玩家尝到甜头 |

| 6 件 | 质变效果 | 终局目标，完全改变 Build 方向 |

**套装设计示例**：

| 套装名 | 2 件 | 4 件 | 6 件 | 获取方式 |
|--------|------|------|------|---------|
| 屠龙者 | 对精英/Boss 伤害 +15% | 击杀精英后 10 秒内伤害 +30% | 攻击 5% 概率触发龙焰（300% AOE） | Boss 掉落 |

**套装部件分布策略**：
- 每个 Boss 掉落特定套装的 1-2 个部件
- 不同 Boss 掉落不同套装，推动玩家多样化刷本
- 赛季套装部件在赛季活动内集中获取

## 第三部分：数值体系深化

### 1. 伤害公式

```
最终伤害 = 武器基础伤害
        × (1 + 装备品质倍率)
        × (1 + 强化倍率)
        × (1 + 攻击加成%)
        × (1 + 暴击修正)
        × (1 + 元素克制)
        × (1 + 猎魔/首领杀手等条件词条)
        × (1 - 目标减伤%)
        × (1 - 目标护甲%)
        × 弱点修正
```

**设计原则**：
- 3-4 个主乘区，避免过多乘法导致数值失控
- 条件词条（猎魔、首领杀手）做独立乘区，鼓励针对配装
- 暴击修正 = 暴击率 × (暴击伤害 - 1) + 1

**M1 简化版（仅 PVE）**：

```
最终伤害 = 武器基础 × 强化倍率 × 怪物类型修正 × 弱点修正
```

### 2. 减伤公式

```
减伤% = 护甲值 / (护甲值 + 护甲常数)
```

- 护甲常数建议值：`玩家等级 × 50 + 200`
- 这样 200 护甲 ≈ 50% 减伤，600 护甲 ≈ 75% 减伤
- 收益递减，防止堆护甲到 100% 减伤

### 4. 数值成长节奏验证

#### 4.1 玩家伤害成长 vs 怪物血量增长

假设一个武器基础伤害 100 的玩家：

| 阶段 | 武器基础 | 品质倍率 | 强化倍率 | 词条加成 | 最终 DPS 倍率 | 对应怪物血量倍率 |
|------|---------|---------|---------|---------|-------------|----------------|
| 入门（白+0） | 100 | 1.0x | 1.0x | 1.0x | **1x** | 1x（普通难度） |
| 成型（紫+8） | 120 | 2.2x | 2.0x | 1.3x | **6.9x** | 6-10x（困难难度） |
| 进阶（橙+12） | 150 | 2.8x | 3.5x | 1.6x | **23.5x** | 20-40x（噩梦难度） |
| 毕业（红+15） | 200 | 3.5x | 5.5x | 2.0x | **77x** | 60-100x（地狱难度） |

**关键验证**：
- 每个阶段的伤害成长（约 3-7 倍）略快于怪物血量增长
- 成型玩家打入门本可以割草（6.9x 伤害 vs 1x 血量）
- 但打同级本需要配装和一定操作

#### 4.2 TTK（击杀时间）设计目标

| 怪物类型 | 同级 TTK 目标 | 跨级 TTK（+1 阶装备打 -1 阶难度） |
|---------|-------------|-------------------------------|
| 普通小怪 | 0.8-2.0 秒 | 0.3-0.8 秒（割草） |
| 远程怪 | 1.5-3.0 秒 | 0.8-1.5 秒 |
| 精英怪 | 30-90 秒 | 15-40 秒 |
| Boss | 90-180 秒 | 45-90 秒 |

### 6. 经济数值

#### 6.1 货币产出与消耗

| 货币 | 单局产出（正常撤离） | 主要消耗 | 单次消耗量 |
|------|-------------------|---------|----------|
| 金币 | 2000-5000 | 强化 +1~+5、修理 | 500-2000 |
| 基础强化石 | 3-8 个 | 强化 +1~+5 | 1-3 个/次 |
| 高级强化石 | 0-2 个 | 强化 +6~+12 | 2-5 个/次 |
| 晶核 | 0-1 个 | 强化 +9~+15、洗练 | 1-3 个/次 |
| Boss 核心 | 0.1-0.3 个 | 强化 +13~+15、合成橙装 | 1 个/次 |

#### 6.2 赛季经济节奏

| 赛季阶段 | 时长 | 主要经济活动 |
|---------|------|------------|
| 初期 | 第 1-2 周 | 基础材料紧缺，装备快速迭代 |
| 中期 | 第 3-6 周 | 橙装开始出现，强化材料竞争 |
| 末期 | 第 7-8 周 | 红装 + 完美词条追求，PvP 竞争加剧 |
| 赛季结算 | 第 9 周 | 部分排行重置，基础装备保留 |

### 7. 数值风险与验证方法

| 风险 | 检测方法 | 应对 |
|------|---------|------|
| 数值膨胀过快 | 追踪 7 天/30 天平均战力，目标月增长 3-5x | 下调后期强化倍率 |
| 某种词条必选 | 统计装备使用率，单条超过 70% 视为失衡 | Buff 弱势词条或 Nerf 过强词条 |
| Boss 掉落太稳定 | 追踪 Boss 击杀→橙装产出比 | 调整掉率或增加消耗口 |
| 新玩家追不上 | 追踪新玩家 7 天战力/老玩家战力比 | 追赶机制（新手加成/赛季重置） |
| PVE 数值破坏 PVP | PVP 中使用独立倍率表 | 所有攻击词条在 PVP 中衰减到 20-30% |

## 第四部分：关卡简化与推进感替代设计

### 1. 核心原则

传统射击关卡 = 走廊 + 演出 + 机关 + 剧情。传奇 = 一个野外地图，怪物在那刷，你去打。

**目标：把"关卡"简化为"战斗场"，同时不丢失推进感。**

### 2. 推荐方案：2-3 层深度结构

```
第一层 · 矿道入口                    第二层 · 军械残库
┌─────────────────┐          ┌─────────────────┐
│                 │          │                 │
│  行尸×10        │   门     │  枪兵+行尸×15    │
│  新手热身       │────────→│  精英怪×1       │
│                 │          │                 │
│  👤出生点    🚪 │          │  🚪 撤离点      │
└─────────────────┘          └────────┬────────┘
                                      │ 传送门 (击杀精英激活)
                                      ↓
                        第三层 · 地宫祭坛
                        ┌─────────────────┐
                        │                 │
                        │  Boss + 怪海     │
                        │  最高收益        │
                        │                 │
                        │  🚪 Boss撤离点   │
                        └─────────────────┘
```

**核心规则**：
- 每层是一个独立的战斗 Arena（约 30-50m²），不是走廊
- 清够怪物数量 → 下一层入口激活
- 中间层就有撤离点，玩家随时可选"撤"
- 第三层是贪婪路线——更好的掉落，更高的风险

**层 ≠ 关卡**

| 是 | 不是 |
|---|------|
| 每层一个 Arena，约 30-50m² | 每层有走廊连接的大地图 |
| 清怪计数激活门 | 跑路、找钥匙、开机关 |
| 每层怪物组合不同 | 每层有独立剧情 |
| 三层共用一套撤离规则 | 每层有独立结算 |
| M1 可同 Arena 换灯光颜色 | 三个完全不同美术风格的场景 |

### 3. M1 极简做法

三层用同一张 Arena 模板，只换：
- 怪物配置（一层近战为主 / 二层远程+精英 / 三层 Boss+怪海）
- 灯光颜色（一层蓝 / 二层黄 / 三层红）
- 刷新点位置微调

开发成本几乎为零，但玩家感知完全不同。

### 4. 三层风险等级

```
一层（矿道）：   "打工层" — 无风险，稳赚基础材料
二层（军械库）： "博弈层" — 有精英，蓝紫装机会，有撤离点
三层（祭坛）：   "赌命层" — Boss + 橙装机会，只有 Boss 撤离点
```

与传奇"安全区→野外→危险地图"逻辑一致。

### 5. 推进感的三种替代来源

传统射击用"空间探索"制造推进感。去掉空间推进后，用以下三种替代：

#### 5.1 时间推进：难度螺旋上升

```
开局0分钟        5分钟            10分钟            15分钟
  │               │                │                 │
  ├─ 行尸×5       ├─ 行尸×8        ├─ 行尸×10        ├─ Boss+
  │  轻松清完      │  +枪兵×3       │  +枪兵×5         │  精英+小怪海
  │               │  +爆裂虫×2     │  +爆裂虫×4       │
  │               │  +精英怪×1     │  +精英怪×2       │
  │               │                │                 │
  └─ 热身期       └─ 压力期        └─ 高压期         └─ 高潮
     "随便打"        "需要走位了"     "还能不能撑住？"   "撤还是打？！"
```

不需要空间变化，玩家能清晰感受到"局势在升级"。

#### 5.2 收益推进：背包价值持续膨胀

| 时刻 | 背包状态 | 玩家心理 |
|------|---------|---------|
| 开局 | 空的 | "赶紧出货" |
| 第一件蓝装 | 值 500 | "有保底了" |
| 精英掉了紫装 | 值 3000 | "稳了...但还想贪" |
| 紫装+材料攒满 | 值 8000 | "撤离点在哪，我得活着出去" |
| Boss 掉了橙装图纸 | 值 20000+ | 手心出汗，每一步都紧张 |

这种推进不是空间给的，是**背包里东西越来越值钱**给的。

#### 5.3 目标推进：击杀计数 → Boss 登场

```
击杀计数：0/20  →  15/20  →  20/20 → 精英登场！
                "快了快了"
                        击杀精英
                           ↓
              击杀计数：0/40  →  30/40 → 40/40 → Boss 登场！
                                        "来真的了"
```

玩家一直在期待下一个目标，推进感来自倒计时。

### 6. 一局完整情绪曲线

```
时间：  0min ─────── 5min ──────── 10min ─────── 15min
        │            │             │              │
时间推进 │ 行尸稀稀拉拉 │ 枪兵+爆裂虫  │ 精英+怪海     │ Boss+全屏弹幕
        │            │             │              │
收益推进 │ 白装×2     │ 蓝装+紫材料  │ 紫装+高级石   │ 橙装图纸！
        │ "有就行"   │ "值了"       │ "不能死"     │ "这把必须活！"
        │            │             │              │
目标推进 │ 0/20 →     │ 20/20!精英  │ 0/40 →       │ 40/40! Boss
        │ "随便打"   │ "来了来了"   │ "还差一点"    │ "打还是撤？！"
        │            │             │              │
情绪曲线 │ 😌 轻松    │ 😏 投入      │ 😰 紧张      │ 🔥 高潮
```

三种推进叠加——当 Boss 登场的同时背包里有一件橙装图纸，那一刻的"要活着出去"是最强的。

### 7. 单局变量设计（防腻）

| 变量 | 说明 | 频率 |
|------|------|------|
| 随机事件 | 地宫商人、哥布林盗贼、诅咒宝箱 | 每局 1-2 次 |
| 精英变体 | 同一刷新点，重甲矿奴/地宫祭司随机 | 每次不同 |
| Boss 池 | 3-5 个 Boss 随机抽取 | 每局不同 |
| 词缀天气 | 毒雾（掉血+20%掉落）、能量风暴（双方增伤） | 每日轮换 |

## 第五部分：终局内容与数值成长终点

### 1. 核心问题

数值成长到后面怎么办？如果只是"打更高难度副本"，到了地狱难度就撞墙了。

### 2. 数值分层不跟随

**副本不能跟玩家一起涨。** 正确做法是分层固定：

```
玩家战力 ──────────────────────────────────────→

普通难度        困难难度        噩梦难度        地狱难度
(入门)          (成型)          (进阶)          (毕业)
怪物固定        怪物固定        怪物固定        怪物固定
白绿装够打       紫+8够打        橙+12够打       红+15套装才够
```

### 3. 三种爽点驱动

| 爽点类型 | 场景 | 体感 |
|---------|------|------|
| **挑战爽** | 第一次进地狱难度，丝血通 Boss | "我操作真牛逼" |
| **成长爽（割草）** | 成型后回头刷普通难度，一梭子全倒 | "我装备真牛逼" |
| **博弈爽** | 背包有橙装，队友死了俩，离撤离点 30 秒 | "这把必须活" |

三者缺一不可。只有挑战累，只有割草腻。撤离玩法天然提供第三种。

**玩家日常行为分布：**

| 玩家状态 | 做什么 | 体验 |
|---------|--------|------|
| 刚成型（紫+8） | 打困难本获取金装材料 | 有挑战，需要配装和走位 |
| 装备溢出（金+12） | 回普通本刷基础材料 | 碾压，一分钟清场 |
| 差一件套装 | 打噩梦本赌 BOSS 掉落 | 高风险，心跳加速 |
| 毕业（红+15） | 带新人/刷排名/备战沙城 | 社交+荣誉追求 |

### 4. 五条终局路线

```
                ┌─── 高难副本毕业（地狱全通，红装+15 全套）
                │
数值成长 ───────┼─── 世界 Boss 争夺（定时刷新，全服争夺）
                │
                ├─── 沙城/公会战（阵营对抗，占领收益）
                │
                ├─── 赛季重置竞赛（新套装/新流派，重新冲排名）
                │
                └─── 完美主义收集（全词条 T4、全套装、全 Boss 无伤）
```

#### 4.1 高难副本分层

```
普通 ──→ 困难 ──→ 噩梦 ──→ 地狱 ──→ 深渊（限时/限次）
  5min    10min    15min    20min    每周开放3次
```

- 地狱是常规最高难度
- 深渊本每周只开 3 次，门票靠日常任务攒
- 深渊产出赛季红装材料和唯一外观
- "毕业"不是终点——每周还要回来打深渊

#### 4.2 世界 Boss

| 设计要素 | 内容 |
|---------|------|
| 刷新时间 | 每日固定时段（如 20:00、22:00） |
| 刷新数量 | 全服 1 只 / 每个频道 1 只 |
| 争夺方式 | 多队同时对 Boss 输出，按伤害贡献排名分配掉落 |
| 核心奖励 | 红装材料、专属称号、Boss 坐骑/皮肤 |
| 传奇感 | 全服公告 "XXX 对世界 Boss 造成最后一击"，掉落全服可见 |

#### 4.3 赛季重置（核心留存机制）

**数值不是无限涨的：**

```
赛季初（第1周）         赛季中（第4-6周）        赛季末（第8周）
   │                      │                      │
   ├─ 战力归零            ├─ 金装成型            ├─ 红装毕业
   ├─ 新套装上线           ├─ 冲排名              ├─ 沙城战决赛
   ├─ 新 Boss             ├─ 公会招人            ├─ 排行榜定格
   └─ 同一起跑线          └─ 交易活跃            └─ 赛季结算奖励
```

| 重置什么 | 保留什么 |
|---------|---------|
| 赛季排行榜排名 | 已获得的装备（降为基础版，可继续用） |
| 赛季通行证等级 | 皮肤、称号、外观收藏 |
| 赛季专属货币 | 金币、基础强化石（部分折算继承） |
| 公会排名积分 | 公会等级和公会科技 |

每个赛季都是一次"重新出发"，但老玩家有收藏和经验的优势，新玩家不会觉得永远追不上。

#### 4.4 完美主义收集

给硬核玩家一个"永远做不完"的目标：
- 全装备词条 T4 毕业
- 全 Boss 无伤成就
- 全套装 6 件激活
- 全称号收集
- 全 Boss 速通排名 TOP100

### 5. 终局心态转变

| 传统射击 | 你的游戏 |
|---------|---------|
| 通关地狱难度 = 游戏结束 | 地狱难度 = 终局的开始 |
| 装备是通关工具 | 装备是身份标识 + 社交资本 |
| 终点是游戏内容耗尽 | 终点是赛季重置/下一个目标 |
| 玩家问"后面还有关卡吗" | 玩家问"今晚世界 Boss 几点刷" |

## 第六部分：爬塔系统

### 1. 系统定位

爬塔不是取代副本，而是**副本之外的第二条成长验证线**：

```
副本（刷装）                   爬塔（验装）
──────────                    ──────────
进去刷怪爆装                   不刷掉落，只验证战力
活着带出来                     爬得越高越牛逼
产出：装备 + 材料              产出：排名 + 称号 + 赛季奖励
"我今天出了件橙装"             "我今天爬到了87层"
```

**两者的闭环关系：**

```
刷副本 ──→ 出装备 ──→ 强化 ──→ 爬塔验证战力 ──→ 爬不动了
   ↑                                                  │
   └──────────── 回副本刷更好的装备 ←─────────────────┘
```

爬塔给出一个明确的**"我变强了吗"的答案**，而不是让玩家凭感觉。

### 2. 每层结构

```
┌─────────────────────┐
│  第 N 层 · 废土深渊  │
│                     │
│  👤 进入点           │
│                     │
│  ░░░░░ 怪物刷新 ░░░░ │  ← 一层就是一个 Arena
│                     │
│  🚪 下一层传送门      │  ← 清完激活
│  🚪 退出传送门       │  ← 随时可退
│                     │
└─────────────────────┘
```

### 3. 阶梯结构

| 层级 | 怪物 | 核心奖励 | 难度 |
|------|------|---------|------|
| 1-10 层 | 普通行尸+枪兵 | 金币、基础强化石 | 入门，白绿装可通 |
| 11-30 层 | 行尸+枪兵+自爆虫 | 高级强化石、蓝装 | 蓝紫装+5 可通 |
| 31-60 层 | 精英×1 + 怪群 | 晶核、紫装、图纸碎片 | 紫装+10 可通 |
| 61-80 层 | 双精英 + 特殊词缀 | Boss 核心、橙装图纸 | 橙装+13 可通 |
| 81-100 层 | Boss 级每 5 层 + 双精英 | 红装材料、专属称号 | 红装+15 可通 |
| 100+ 层 | 无限叠加（每层怪物属性 +5%） | 排名积分、赛季奖杯 | 赛季终局追求 |

### 4. 爬塔与副本的关键差异

| | 副本 | 爬塔 |
|---|---|---|
| 地图 | 2-3 层深度结构 | 每层一个 Arena |
| 掉落 | 怪会爆装备，背包系统 | 不掉落，只给结算奖励 |
| 风险 | 死亡损失未结算物资 | 死亡不掉东西，但本次进度作废 |
| 撤离 | 随时撤离保留收益 | 每 5 层一个"存档点"，退出后可从存档点继续 |
| 目的 | 获取装备 | 验证装备 + 社交排名 |
| 重置 | 赛季部分重置 | 每赛季重新爬 |

### 5. 存档点设计（降低挫败）

```
第 5 层 ──→ 存档 ✓ (退出后可从这里继续)
第 10 层 ──→ 存档 ✓ + 结算奖励
第 15 层 ──→ 存档 ✓
第 20 层 ──→ 存档 ✓ + Boss·层主 + 大奖励
第 25 层 ──→ 存档 ✓
第 30 层 ──→ 存档 ✓ + Boss·层主 + 大奖励
...每 5 层一次存档，每 10 层一次 Boss
```

死亡回到上一个存档点，挫败感可控。

### 6. 特殊层设计

纯重复会腻。在重复层之间插入特殊层：

```
第 5 层  · 宝藏层 — 大量金币 + 材料，轻松收割
第 10 层 · Boss 层 — 层主把守，通关后大奖励
第 15 层 · 限时层 — 90 秒内清完，额外奖励
第 20 层 · Boss 层 — 层主
第 25 层 · 词缀层 — 本层"所有怪物带冰冻"，考验配装
第 30 层 · Boss 层
第 35 层 · 挑战层 — "只用副武器通关"额外奖励宝箱
第 40 层 · Boss 层（双 Boss）
...
第 50 层 · 赛季 Boss — 赛季专属 Boss，全服首杀广播
第 100 层 · 深渊之主 — 赛季终极 Boss，顶级称号
```

每 5 层只需要一个"不一样的东西"，大部分层还是重复 Arena + 数值递增。开发成本低，玩家感知丰富。

### 7. 排名驱动

爬塔最大的价值是**社交比较**：

| 排名维度 | 说明 |
|---------|------|
| 单人最高层 | 个人战力证明 |
| 赛季首次通关层数 | 鼓励每个赛季重新挑战 |
| 最快通关速度 | 某段（如 1-30 层）的最快时间 |
| 公会总层数 | 所有公会成员的层数总和 |
| 武器限定挑战 | 只用突击步枪、只用副武器爬塔 |

**赛季结算奖励：**

| 排名 | 奖励 |
|------|------|
| TOP 1% | 传说称号 + 专属外观 + 下赛季初始跳过 10 层 |
| TOP 5% | 史诗称号 + 限时皮肤 |
| TOP 20% | 稀有称号 |
| 全服前 3 | 全区广播 |

### 8. 终局路线总览

```
                          ┌── 爬塔（验装 + 排名）
                          │
准备 → 进副本 → 刷装 → 强化 ──┼── 世界 Boss（社交 + 争夺）
                          │
                          └── 沙城战（公会 + 赛季高潮）
```

三个终局出口，分别满足不同玩家：

| 玩家类型 | 核心追求 |
