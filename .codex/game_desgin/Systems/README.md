# 系统拆分与第一阶段任务

> 对应主案：`../GDD.md` V0.2
> 当前制作目标：先验证“PVE 爆装撤离”闭环，再逐步加入 PVP、商业化和行会目标。

## 第一阶段总目标

第一阶段只回答一个问题：玩家能不能完成一局“进图刷怪、爆出物资、封存关键物品、撤离入库、强化变强、再进一局”的闭环，并觉得值得继续玩。

第一阶段不追求完整内容量，追求闭环可靠：

```text
准备装备
  -> 进入废土地宫灰盒
  -> 普通怪/精英怪战斗
  -> 掉落进入未结算背包
  -> 保险箱保护少量物品
  -> 撤离成功或死亡失败
  -> 结算展示收益/损失
  -> 强化装备
  -> 下一局效率提升
```

## 当前版本总验收

首版不是验证“类传奇大世界”，而是验证这条链路：

```text
进入废土地宫
  -> 射击清怪
  -> 打精英 / Boss 占位目标
  -> 爆出未结算物资
  -> 选择保险箱封存或继续贪
  -> 撤离成功或死亡失败
  -> 结算入库 / 损失
  -> 强化装备
  -> 再进一局
```

如果这条链路不够爽，后续 PVP、行会、商业化都没有意义。

## 第一阶段总交付清单

| 模块 | 必须完成 |
| --- | --- |
| 地图 | 1 张废土地宫灰盒，包含出生点、普通区、精英区、Boss 区、固定撤离点 |
| 战斗 | 行尸、枪兵、1 个精英怪，Boss 可先占位 |
| 掉落 | 普通怪、精英怪、Boss 各自掉落表，品质颜色表现 |
| 背包 | 本局未结算物资列表，撤离后入库 |
| 撤离 | 固定撤离点倒计时，撤离成功结算 |
| 死亡 | 死亡失败结算，未结算物资损失 |
| 保险箱 | 免费 2 格，死亡后保留 |
| 成长 | 金币 + 强化石强化 1 项武器属性 |
| 任务 | 击杀、拾取、撤离 3 个事件埋点 |
| 技术验证 | UGC 怪物刷新、通用掉落、V2 背包/临时收益表、触发器和伤害公式预留 |

## M1 前置技术门禁

这些验证没跑通前，不进入大规模地图和内容铺量：

| 门禁 | 通过标准 |
| --- | --- |
| 怪物刷新和死亡回调 | 1 个刷新点能生成怪物，死亡只触发 1 次服务端回调 |
| 掉落拾取 | 怪物死亡生成测试物品，玩家拾取后进入本局未结算列表 |
| 撤离结算 | 固定撤离点能把未结算物资转入已结算/仓库，且不会重复结算 |
| 死亡损失 | 玩家死亡后只处理本局未结算物资，已穿戴装备保留 |
| 保险箱 | 2 格保护列表中的物品死亡后保留，未保护物品按规则损失 |

## 第一阶段不做

- 多地图。
- 完整职业。
- 交易系统。
- 完整 PVP 红名生态。
- 完整赛季通行证。
- 行会和沙城战。
- 大量装备词条和复杂洗练。
