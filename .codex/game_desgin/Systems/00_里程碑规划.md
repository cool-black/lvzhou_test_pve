# 00 里程碑规划

> 对应主案：`../GDD.md` V0.2  
> 对应系统拆分：`01` 到 `07` 号系统文档  
> 当前制作原则：先证明“PVE 刷宝撤离”能让玩家反复开局，再逐步加入 Boss 争夺、长期成长、赛季商业化和行会沙城。

---

## 1. 总体路线

本项目的优先级不是同时做成“射击 + 传奇 + 搜打撤 + 行会战”的完整大盘，而是按风险从高到低逐层验证。

```text
M0 技术门禁
  -> M1 PVE 爆装撤离灰盒
  -> M2 射击休闲化与关卡推进感
  -> M3 Boss 高价值目标与 PVP 争夺压力
  -> M4 装备成长与经济留存
  -> M5 任务、赛季与商业化
  -> M6 终局玩法与爬塔验证
  -> M7 行会、世界 Boss 与沙城战
```

阶段推进底线：

- M1 没跑顺，不进入内容铺量。
- PVE 打怪不好玩，不急着开放 PVP。
- 掉落、撤离、保险箱不稳定，不接商业化。
- 5-10 局成长不成立，不做赛季和行会。
- PVP 必须服务高收益区压力，不能压过 PVE 刷宝主体验。

## 2. 里程碑总览

| 里程碑 | 阶段目标 | 核心验收问题 | 主要依据 |
| --- | --- | --- | --- |
| M0：UGC 技术门禁 | 先验证关键能力能不能做 | 怪物、掉落、未结算、撤离、保险箱是否有可用方案 | `05_UGC实现与技术验证.md` |
| M1：PVE 爆装撤离灰盒 | 跑通最小可玩闭环 | 玩家能否完整打一局、带出收益、强化后再进 | `01`、`03`、`04`、`M1里程碑` |
| M2：射击休闲化与推进感 | 让闭环开始“好玩” | 清怪是否爽，掉落是否有期待，地图推进是否清楚 | `02`、`07` |
| M3：Boss 与争夺压力 | 加入单局高潮和高收益风险 | Boss 是否值得打，PVP 是否只在高收益区制造压力 | `02`、`04` |
| M4：成长与经济留存 | 建立多局追求 | 玩家 5-10 局后是否仍有明确装备和材料目标 | `03`、`07` |
| M5：任务、赛季与商业化 | 接入长期目标和低风险付费 | 任务是否顺路，付费是否不破坏公平 | `06` |
| M6：终局玩法与爬塔 | 验证赛季终局出口 | 高难、爬塔、世界 Boss 是否能承接毕业玩家 | `07` |
| M7：行会与沙城战 | 建立中后期社交目标 | 行会是否形成组织消耗和每周核心事件 | `GDD`、`06` |

## 3. M0：UGC 技术门禁

### 3.1 阶段目标

M0 不是玩家版本，而是制作可行性验证。所有高风险系统先做最小样例，避免地图和内容铺开后才发现底层规则无法落地。

### 3.2 必过门禁

| 门禁 | 通过标准 | 失败降级方案 |
| --- | --- | --- |
| 怪物刷新和死亡回调 | 1 个刷新点能生成怪物，死亡只触发 1 次服务端回调 | 先手动生成怪物并监听死亡事件 |
| 掉落拾取 | 怪物死亡生成测试物品，玩家拾取后进入本局未结算列表 | 不依赖正式背包，直接写入 `RunLootState` |
| 未结算物资 | 拾取物默认未结算，撤离后转为已结算或入库 | 用服务端本局收益表模拟 |
| 固定撤离结算 | 撤离点能稳定结算，重复进出不会重复发奖 | 服务端维护 `Extracted` 防重 |
| 死亡损失 | 死亡只处理本局未结算物资，已穿戴装备保留 | 不改正式背包，只清理临时收益表 |
| 保险箱保留 | 2 格保护列表中的物品死亡后保留 | 使用独立保护列表，结算时重新发放 |
| 伤害公式预留 | 能区分玩家目标和怪物目标 | 先只做日志和倍率占位 |

### 3.3 通过后产出

- 一份 UGC 限制记录：哪些设计可做，哪些需要替代方案。
- 一套最小数据结构：本局收益、保险箱、撤离状态、死亡状态。
- 一条可继续进入 M1 的技术路径。

## 4. M1：PVE 爆装撤离灰盒

### 4.1 阶段目标

M1 只回答一个问题：玩家是否愿意反复完成“打、爆、装、撤、变强”。

```text
进入废土地宫
  -> 射击清怪
  -> 获得未结算掉落
  -> 击杀 1 个精英 / Boss 占位目标
  -> 选择保险箱封存或继续推进
  -> 固定撤离点撤离，或死亡失败
  -> 结算展示带出 / 损失 / 保险箱保留
  -> 消耗金币和强化石强化武器
  -> 下一局清怪效率提升
```

### 4.2 内容范围

| 模块 | 必做内容 | 完成标准 |
| --- | --- | --- |
| 单局状态 | 准备、局内、撤离中、已撤离、死亡、结算 | 状态只能流转一次，不重复结算 |
| 地图 | 1 张废土地宫灰盒 | 出生点、普通区、精英区、Boss 占位区、固定撤离点 |
| 怪物 | 污染行尸、废土枪兵、1 个精英怪 | 能刷新、攻击、死亡、触发掉落 |
| Boss 占位 | 1 个高价值目标怪 | 可用强化精英代替，死亡后掉 Boss 材料 |
| 掉落 | 普通、精英、Boss 掉落表 | 金币、强化石、白绿蓝紫物资、Boss 材料 |
| 未结算 | 本局收益表或临时背包 | 局内拾取默认未结算 |
| 撤离 | 固定撤离点倒计时 | 8-10 秒倒计时，成功后入库 |
| 死亡 | 死亡失败结算 | 穿戴装备保留，未保护物资按规则损失 |
| 保险箱 | 免费 2 格 | 保护列表内物品死亡后保留 |
| 结算 | 简易结算界面 | 展示带出、损失、保险箱保留、最高品质 |
| 成长 | 基础强化 | 金币 + 强化石提升武器伤害或清怪效率 |
| 埋点 | 击杀、拾取、撤离 | 结算可展示本局核心事件 |

### 4.3 M1 不做

- 完整 Boss 三阶段表现。
- Boss 撤离点和随机撤离点。
- 真实玩家 PVP、红名和撤离点蹲守。
- 完整职业、技能树、复杂词条和洗练。
- 交易、月卡、通行证、付费扩容。
- 行会、沙城战、世界 Boss、爬塔。

### 4.4 验收标准

| 指标 | 目标 |
| --- | --- |
| 首次战斗 | 进入地图 1 分钟内看到敌人，3 分钟内完成第一波 |
| 单局时长 | 灰盒可先压缩到 10-12 分钟 |
| 有效掉落 | 单局 3-5 次有效掉落反馈 |
| 精英目标 | 8-10 分钟内遇到精英或高价值目标 |
| 死亡理解 | 玩家能理解损失、保留和保险箱救回了什么 |
| 撤离理解 | 玩家能理解撤离后物资入库 |
| 成长反馈 | +3 后普通区清怪时间下降 20% 以上 |
| 稳定性 | 连续 10 局无重复结算、物品丢失、撤离失效 |

## 5. M2：射击休闲化与关卡推进感

### 5.1 阶段目标

M2 在 M1 闭环成立后，把“能玩”推进到“想再来一把”。重点不是增加大地图，而是降低射击门槛、强化掉落爽感，并用 2-3 层 Arena 结构制造推进感。

### 5.2 内容范围

| 模块 | 内容 | 目标 |
| --- | --- | --- |
| 休闲化射击 | PVE 辅助瞄准、弱点扩大、腰射友好、命中判定优化 | 让非硬核 FPS 玩家也能稳定清怪 |
| 伤害反馈 | 普通、暴击、弱点、击杀数字与音效 | 形成刷怪和成长爽感 |
| 掉落表现 | 品质颜色、光柱、稀有音效、全队提示 | 玩家看到蓝紫掉落会立刻想捡和撤 |
| 三层 Arena | 矿道入口、军械残库、地宫祭坛 | 用层级替代复杂关卡探索 |
| 推进规则 | 击杀计数、精英触发、Boss 目标提示 | 让玩家知道下一步做什么 |
| 怪物补全 | 爆裂虫、精英弱点或召唤机制 | 普通怪不只是血量差异 |
| 技能占位 | 1 个 AOE 手雷强化或追踪类技能 | 给枪法弱玩家替代解法 |

### 5.3 验收标准

- 普通怪同级 TTK 约 0.8-2.0 秒，枪兵约 1.5-3.0 秒。
- 玩家能用身体命中、弱点命中、技能清怪三种方式获得正反馈。
- 三层结构能表达“打工层、博弈层、赌命层”的风险递增。
- 第一次蓝装、紫装或 Boss 材料掉落能制造“现在该撤了”的情绪。
- 新玩家不看策划说明，也能理解路线、目标和撤离点。

## 6. M3：Boss 高价值目标与 PVP 争夺压力

### 6.1 阶段目标

M3 加入单局高潮和其他玩家压力。PVP 的定位是高收益区风险，不是首要玩法宣传点；普通刷宝路线必须仍然能避战和提前撤离。

### 6.2 内容范围

| 模块 | 内容 | 目标 |
| --- | --- | --- |
| 赤铁魔将 Boss | 三阶段：守门者、召唤者、狂暴者 | Boss 不只是厚血条 |
| Boss 战利品箱 | Boss 材料、橙色图纸碎片、紫装机会 | 让玩家产生带货撤离压力 |
| Boss 撤离点 | Boss 死亡后 90 秒短时开放 | 制造“打完赶紧走”的选择 |
| 随机撤离点 | 中段开放备用撤离路线 | 缓解固定点蹲守 |
| Boss 区 PVP 开关 | 仅高收益区允许互伤 | PVP 服务资源争夺 |
| PVE/PVP 倍率 | 装备词条对玩家衰减 | PVP 操作影响 70%-80% |
| 掉落归属 | 小队归属或贡献白名单 | 降低抢队友和抢尾刀争议 |

### 6.3 验收标准

- Boss 是单局最想打但不一定非打不可的目标。
- Boss 击杀后，玩家会在继续搜、封存、快速撤离之间做选择。
- PVP 只在高收益区形成压力，不让新手路线变成劝退区。
- 装备成长在 PVE 明显，在 PVP 不形成不可反制碾压。
- Boss 掉落归属、撤离点和死亡损失不会产生重复发奖或错误丢失。

## 7. M4：装备成长与经济留存

### 7.1 阶段目标

M4 让玩家 5-10 局后仍有明确目标：刷更好的装备、强化更高等级、补齐关键词条、挑战更高难度。

### 7.2 内容范围

| 模块 | 内容 | 目标 |
| --- | --- | --- |
| 装备品质 | 白、绿、蓝、紫完整；橙以图纸/材料为主 | 防止 3-5 局毕业 |
| 装备槽位 | 主武器 + 简化头盔/护甲/背包 | 建立基础配装空间 |
| 强化 | +1 到 +5 完整，预留 +6 到 +8 | 提供稳定材料消耗口 |
| 词条 | 猎魔、快填、稳定、首领杀手 | 先做能改变体验的少量词条 |
| 未鉴定装备 | 撤离后开奖 | 提升结算期待 |
| 仓库和商店 | 基础仓库、补给商店、修理/补给消耗 | 支撑多局循环 |
| 难度分层 | 普通、困难雏形 | 让成长带来割草和挑战两种体验 |
| 经济记录 | 产出、消耗、撤离率、死亡率 | 发现掉落膨胀或消耗不足 |

### 7.3 验收标准

- 玩家 3 局内至少完成 1-2 次强化。
- 玩家 5 局后能说出下一局想刷什么。
- 普通撤离收益主要是金币、强化石、1-2 件绿/蓝物资。
- 精英和 Boss 收益明显更好，但不会快速毕业。
- 材料有稳定消耗口，不只是越堆越多。

## 8. M5：任务、赛季与商业化

### 8.1 阶段目标

M5 在核心留存成立后接入长期目标和付费结构。商业化只做损失保护、便利和外观，不出售战斗胜利。

### 8.2 内容范围

| 模块 | 内容 | 目标 |
| --- | --- | --- |
| 新手任务 | 进图、击杀、拾取、封存、撤离、强化 | 引导玩家自然跑通核心循环 |
| 日常任务 | 击杀、精英、撤离、带出物资、保险箱封存 | 不打断刷宝节奏 |
| 周常任务 | Boss 击杀、高难撤离、小队协作 | 提供中期目标 |
| 赛季等级 | 任务经验、外观、称号、材料返还券 | 建立 4-8 周追求 |
| 月卡 | 保险箱 +1、每日材料、封存券 | 降低损失，不加战斗力 |
| 通行证 | 外观、称号、保险箱皮肤、撤离特效 | 以收藏和便利为主 |
| 红线检查 | 不卖顶级成品，不卖 PVP 数值碾压 | 保护刷宝价值 |

### 8.3 验收标准

- 新手按任务走能自然完成第一局，而不是被 UI 打断。
- 日常和周常都能在核心玩法中顺路完成。
- 免费玩家保留基础 2 格保险箱，并能完整体验核心循环。
- 付费点不直接提升 PVP 伤害、防御或掉率碾压。
- Boss 核心、据点目标物等最高价值物不能被完全无风险保护。

## 9. M6：终局玩法与爬塔验证

### 9.1 阶段目标

M6 用高难副本、爬塔和世界 Boss 验证装备成长的终点。目标不是无限堆数值，而是给不同玩家提供挑战、割草、排名和社交争夺出口。

### 9.2 内容范围

| 模块 | 内容 | 目标 |
| --- | --- | --- |
| 难度固定分层 | 普通、困难、噩梦、地狱 | 玩家变强后能回头割草，也能向上挑战 |
| 高难 Boss | 噩梦/地狱参数和机制加强 | 承接橙装、红装追求 |
| 爬塔 | 每层 Arena、每 5 层存档、每 10 层 Boss | 验证战力和排名 |
| 特殊层 | 宝藏层、限时层、词缀层、挑战层 | 降低重复疲劳 |
| 排行榜 | 单人最高层、速通、公会总层数 | 提供赛季比较 |
| 世界 Boss 雏形 | 定时刷新、贡献奖励、全服提示 | 为行会和社交争夺铺路 |
| 赛季重置草案 | 排行重置、收藏保留、材料折算 | 新老玩家都能重新进入竞争 |

### 9.3 验收标准

- 成型玩家打低难有明显割草感，打同级难度仍需要配装和走位。
- 爬塔能清楚回答“我变强了吗”。
- 排行和称号能驱动硬核玩家继续刷装。
- 世界 Boss 不会让普通副本失去价值。
- 赛季重置不会让玩家觉得已有投入全部作废。

## 10. M7：行会、世界 Boss 与沙城战

### 10.1 阶段目标

M7 建立中后期社交组织和每周事件。行会不用于拯救不好玩的核心循环，只在单局、成长和终局都成立后放大长期目标。

### 10.2 内容范围

| 模块 | 内容 | 目标 |
| --- | --- | --- |
| 行会 1.0 | 创建、成员、职位、捐献、行会科技 | 建立组织和资源消耗口 |
| 行会 2.0 | 行会 Boss、行会仓库、行会商店 | 建立组织刷宝目标 |
| 据点争夺 | 小型旗点、复活点、补给点 | 先验证小规模阵营 PVP |
| 沙城战 | 报名、旗点积分、复活规则、补给车、炮台 | 建立每周核心事件 |
| 行会奖励 | 专属称号、外观、商店权益、资源分成 | 强化荣誉和组织归属 |

### 10.3 验收标准

- 行会有持续资源需求，而不是只做聊天列表。
- 行会 Boss 和据点争夺能消耗中后期装备和材料。
- 沙城战能成为每周事件，但不破坏普通玩家 PVE 追求。
- 大型 PVP 仍遵守 PVE/PVP 倍率分离，不让装备数值完全碾压操作。

## 11. 共用数据看板

从 M1 开始，每个版本至少记录这些数据，用来判断是否进入下一里程碑。

| 数据 | 用途 |
| --- | --- |
| 平均单局时长 | 判断节奏是否过长或过短 |
| 首次战斗时间 | 判断开局是否迷路或空窗 |
| 有效掉落次数 | 判断刷宝反馈是否足够 |
| 撤离率 / 死亡率 | 判断风险和挫败是否合理 |
| 平均带出价值 / 损失价值 | 判断经济产出和死亡惩罚 |
| 保险箱使用率 | 判断玩家是否理解风险保护 |
| 强化次数和强化等级分布 | 判断成长速度 |
| 普通怪 / 精英 / Boss TTK | 判断战斗和数值是否健康 |
| 任务完成率 | 判断引导是否顺路 |
| PVP 击杀地点和原因 | 判断 PVP 是否劝退 PVE 玩家 |

## 12. 当前执行建议

当前只进入 M0/M1，不提前实现 M2+ 的大系统。短期工作应集中在：

1. 按 `../M1里程碑/00_M1执行总表.md` 通过技术门禁。
