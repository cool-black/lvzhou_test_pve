# 01 核心循环与 MVP

## 1. 系统定位

核心循环是整个项目的骨架。首版不验证“传奇大世界”，也不验证“完整商业化”，只验证玩家是否愿意反复进行这一条链路：

```text
选装备进图
  -> 射击清怪
  -> 获得未结算掉落
  -> 遇到精英 / Boss
  -> 选择继续贪、封存或撤离
  -> 成功撤离入库，死亡损失部分收益
  -> 强化装备
  -> 再进一局
```

第一阶段的目标是做出一个 15 分钟左右的可玩灰盒局，让玩家不用看策划解释，也能理解“打、爆、装、撤、变强”的乐趣。

## 2. 玩家体验目标

- 进入地图 1 分钟内看到敌人，3 分钟内完成第一波清怪。
- 5 分钟内获得至少一次有品质感的掉落反馈。
- 8-10 分钟内遇到精英怪或高价值物资点。
- 12-15 分钟内产生“现在撤还是继续推进 Boss 占位目标”的选择。
- 死亡会痛，但不会让玩家觉得一局白玩。
- 撤离成功后，玩家能明确看到本局收益进入仓库，并获得下一局变强的理由。

## 3. 首版 MVP 范围

| 模块 | 首版做法 | 第一阶段要求 |
| --- | --- | --- |
| 地图 | 1 张废土地宫灰盒 | 有出生点、普通区、精英区、Boss 区、撤离点 |
| 单局时长 | 目标 15 分钟 | 可先用 10-12 分钟压缩验证 |
| 队伍 | 1-4 人 | 第一阶段优先单人和 2 人联机验证 |
| 核心目标 | 刷怪、拿掉落、撤离 | Boss 可先做弱化版目标怪 |
| 失败规则 | 损失未结算物资 | 第一阶段先做固定比例损失 |
| 成长 | 基础强化 | 第一阶段先做局后属性提升或装备替换 |
| PVP | 暂缓或只留 Boss 区测试 | 核心 PVE 闭环成立后再打开 |

## 4. 单局流程设计

### 4.1 局前准备

玩家在安全准备界面完成：

- 选择地图：第一阶段只有“废土地宫”。
- 选择初始装备：系统给默认步枪、手枪、药品、弹药。
- 查看保险箱容量：默认 2 格。
- 查看本局目标：撤离 1 次、击杀精英、带出蓝色物资。

第一阶段可先不做完整 UI，用测试按钮或固定配置进入地图，但流程概念要保留。

### 4.2 局内阶段

| 时间 | 阶段 | 玩家事件 | 设计目的 |
| --- | --- | --- | --- |
| 0:00-1:00 | 进入地图 | 出生、安全补给、看到第一条路线 | 不让玩家迷路 |
| 1:00-3:00 | 普通刷怪 | 污染行尸 + 废土枪兵 | 建立射击清怪节奏 |
| 3:00-5:00 | 初次掉落 | 白绿装、金币、材料、弹药 | 让玩家知道怪会爆东西 |
| 5:00-8:00 | 路线选择 | 稳健撤离路线或深入精英区 | 产生第一次风险选择 |
| 8:00-11:00 | 精英遭遇 | 重甲矿奴或地宫祭司 | 形成小高潮和更好掉落 |
| 11:00-14:00 | Boss 压力 | Boss 区提示或最终怪刷新 | 给贪婪玩家目标 |
| 14:00-16:00 | 撤离决策 | 固定撤离点 | 完成带出收益 |

### 4.3 局后结算

结算必须清楚展示：

- 成功带出的物品。
- 死亡损失的物品。
- 保险箱保留的物品。
- 获得的金币、材料、经验。
- 可进行的强化或下一局推荐目标。

## 5. 路线设计

### 5.1 稳健路线

- 怪物密度低。
- 主要掉落白绿装、金币、基础材料。
- 5-8 分钟即可撤离。
- 目标玩家：新手、残血、背包已有好东西的玩家。

### 5.2 贪婪路线

- 怪物密度中等。
- 有精英怪和蓝紫装机会。
- 距离撤离点更远。
- 目标玩家：想多刷收益的小队。

### 5.3 Boss 路线

- 怪物压力最高。
- 有橙装、图纸、Boss 材料机会。
- 后续可开放 PVP 争夺。
- 目标玩家：高风险高收益玩家。

## 6. 胜负与失败规则

### 6.1 成功

满足任一条件：

- 玩家进入撤离点并完成撤离倒计时。
- 测试阶段可使用调试结算按钮，但必须模拟真实撤离结果。

成功后：

- 未结算物资转为已结算。
- 保险箱物资进入仓库。
- 结算金币、材料、经验。

### 6.2 失败

触发条件：

- 玩家死亡且没有队友救援。
- 单局时间结束未撤离。
- 测试阶段手动触发失败。

失败后：

- 已穿戴装备保留。
- 保险箱物品保留。
- 未结算普通材料损失 50%。
- 未结算蓝色以上物资第一阶段可先全部损失，后续再细化概率。

## 7. 第一阶段要完成的功能

| 优先级 | 功能 | 交付标准 |
| --- | --- | --- |
| P0 | 灰盒地图 | 有出生点、3 个刷怪区、1 个精英区、1 个撤离点 |
| P0 | 单局状态机 | 能从准备、进行中、撤离成功、死亡失败、结算之间流转 |
| P0 | 基础刷怪 | 普通怪按区域刷新，击杀后计数 |
| P0 | 基础掉落 | 怪物死亡生成可拾取物，拾取后进入临时背包 |
| P0 | 未结算物资 | 局内拾取物标记为未结算 |
| P0 | 撤离点 | 玩家进入区域后倒计时，完成后结算 |
| P0 | 死亡失败 | 玩家死亡后结算损失和保留 |
| P0 | 保险箱占位 | 2 格容量，可把物品标记为受保护 |
| P0 | 简易结算界面 | 展示带出、损失、保险箱保留 |
| P1 | 精英目标 | 至少 1 个精英怪，掉落高于普通怪 |
| P1 | Boss 占位 | 可先用高血量精英怪代替 Boss |
| P1 | 基础强化 | 消耗材料提升一项属性或更换更高品质武器 |

## 8. 第一阶段不做

- 多地图选择。
- 完整职业系统。
- 完整红名系统。
- Boss 撤离点。
- 完整行会、沙城、世界 Boss。
- 交易系统。
- 大规模 PVP。
- 完整赛季任务链。
- 复杂装备洗练。

## 9. 开工顺序

1. 做灰盒地图和玩家出生。
2. 接 1 个普通怪刷新点。
3. 接 1 个掉落物拾取到临时背包。
4. 接撤离点和结算。
5. 接死亡失败和未结算损失。
6. 接保险箱保护 1-2 个物品。
7. 加精英怪和更好掉落。
8. 加局后强化，让下一局击杀效率变高。
9. 完整跑 10 局，记录每局收益、死亡率、撤离率、平均时长和强化前后清怪效率。

## 10. 验收标准

- 玩家 3 分钟内能进入战斗。
- 单局至少有 3 次掉落反馈。
- 玩家能区分“已带出”和“未结算”。
- 撤离成功后，玩家能看到明确收益。
- 死亡失败后，玩家至少保留穿戴装备和保险箱物资。
- 完成 3 局后，玩家能感到强化或装备替换带来的效率提升。

### 10.1 M1 跑局数据表

| 指标 | 起始目标 |
| --- | --- |
| 普通怪数量 | 单局 20-30 只 |
| 精英数量 | 单局 1 只 |
| 有效掉落次数 | 单局 3-5 次 |
| 正常撤离带出 | 金币、基础强化石、1-2 件绿/蓝物资 |
| 死亡失败损失 | 普通材料损失 50%，蓝色以上未保护物资先全部损失 |
| 3 局成长目标 | 至少完成 1-2 次强化 |
| 强化反馈 | +3 后普通区平均清怪时间下降 20% 以上 |

## 11. 主要风险

- 系统太多导致第一阶段做不完：必须先打通闭环，再加表现和复杂规则。
- 前 5 分钟没有爆点：普通怪掉落和首次精英提示要提前出现。
- 死亡惩罚过重：首版只损失未结算收益，不掉已穿戴装备。
- 成长反馈太弱：第一阶段哪怕只做一条伤害提升，也要能被玩家感知。
- 玩家不知道去哪：地图必须用路线、灯光、提示或目标点引导。
