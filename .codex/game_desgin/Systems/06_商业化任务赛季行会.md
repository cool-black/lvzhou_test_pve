# 06 商业化、任务、赛季与行会

## 1. 系统定位

商业化、任务、赛季和行会都是长期系统，必须服务核心循环，不能抢在 MVP 前面做大。

第一阶段只做两件事：

- 用击杀、拾取、撤离 3 个事件埋点引导玩家跑通核心流程；完整任务链后置。
- 提前写清商业化红线，避免后续设计走向数值付费。

行会、沙城战和完整赛季不进入第一阶段开发。

## 2. 商业化原则

- 免费玩家必须拥有基础保险箱。
- 付费降低损失、提升便利、提供外观，不直接提升 PVP 战斗力。
- 不直接售卖最高阶装备成品。
- 不出售无法通过玩法获得的核心数值能力。
- 保险箱扩容有上限。
- Boss 核心、据点目标物等高价值目标不能被完全无风险保护。

## 3. 可规划付费点

| 付费点 | 内容 | 上线阶段 | 风险 |
| --- | --- | --- | --- |
| 月卡 | 保险箱 +1、每日材料、每日封存券 | 核心闭环稳定后 | 容易被认为付费保命 |
| 通行证 | 外观、称号、材料返还券、保险箱皮肤 | 赛季系统开启后 | 需要足够任务内容 |
| 保险箱扩容 | 2 格扩到 3-4 格 | P2 | 必须限制上限 |
| 封存芯片 | 单局额外保护 1 件 | P2 | 必须限制使用次数 |
| 仓库扩容 | 增加局外存储空间 | P2 | 风险较低 |
| 预设装备方案 | 快速换装 | P2 | 风险较低 |
| 外观 | 枪皮、背包、撤离特效、称号 | P2 | 推荐 |
| 数值装备售卖 | 直接卖强装备 | 不做 | 破坏公平和刷宝价值 |

## 4. 第一阶段任务系统

任务不是用来填满 UI，而是用来引导玩家理解核心循环。

### 4.1 M1 任务事件埋点

M1 不急着做完整任务 UI，先确保核心事件能被记录、结算界面能展示结果。

| 事件 | 记录目标 | 用途 |
| --- | --- | --- |
| 击杀 | 普通怪击杀数、精英击杀数 | 教玩家刷怪和目标优先级 |
| 拾取 | 拾取物品数量、最高品质、是否未结算 | 教玩家掉落和未结算状态 |
| 撤离 | 撤离成功、带出物资、损失物资 | 教玩家撤离入库和死亡损失 |

### 4.2 后续新手引导任务

| 任务 | 目标 | 奖励 | 设计目的 |
| --- | --- | --- | --- |
| 初入地宫 | 完成 1 次进入地图 | 金币、弹药 | 让玩家开始第一局 |
| 清理污染 | 击杀 10 只普通怪 | 基础强化石 | 教玩家刷怪 |
| 第一件战利品 | 拾取 1 件绿色以上物品 | 金币 | 教玩家掉落拾取 |
| 学会封存 | 放入 1 件物品到保险箱 | 强化石 | 教玩家风险保护 |
| 活着回来 | 完成 1 次撤离 | 蓝色测试装备 | 教玩家撤离入库 |
| 初次强化 | 强化 1 次装备 | 金币返还 | 教玩家局后成长 |

### 4.3 日常任务占位

第一阶段只保留方向，不接完整 UI：

- 击杀 20 只怪物。
- 击杀 1 只精英怪。
- 成功撤离 1 次。
- 带出 3 件绿色以上物资。
- 使用保险箱封存 1 次。

## 5. 赛季系统规划

赛季不是第一阶段内容，但要提前确定方向。

### 5.1 赛季目标

- 给玩家 4-8 周的长期追求。
- 提供外观、称号、材料、保险箱皮肤等奖励。
- 推动玩家挑战 Boss、完成撤离、参与后续 PVP/行会。

### 5.2 赛季内容

| 内容 | 说明 |
| --- | --- |
| 赛季等级 | 完成任务获取经验 |
| 赛季任务 | 每日、每周、挑战任务 |
| 赛季套装 | 外观或低数值收藏，不能直接碾压 |
| 赛季称号 | 撤离大师、Boss 猎人、地宫富豪 |
| 赛季排行榜 | 撤离次数、Boss 击杀、财富带出 |

第一阶段只保留字段和方向，不做完整赛季 UI。

## 6. 行会系统规划

行会是中后期目标，第一阶段不做。原因很简单：核心单局不好玩，行会只会放大空壳。

### 6.1 后续三步推进

| 阶段 | 内容 | 目标 |
| --- | --- | --- |
| 行会 1.0 | 成员、捐献、行会科技 | 建立资源消耗口 |
| 行会 2.0 | 行会 Boss、行会仓库 | 建立组织刷宝目标 |
| 行会 3.0 | 据点争夺、沙城战 | 建立大型 PVP 终局 |

### 6.2 沙城战概念

沙城战是后期每周事件：

- 多行会争夺核心据点。
- 占领旗点获得积分。
- 控制复活点、补给车、炮台获得战术优势。
- 胜利行会获得专属商店、称号、资源收益。

这些只做方向，不进入当前开发。

## 7. 第一阶段要完成的功能

| 优先级 | 功能 | 交付标准 |
| --- | --- | --- |
| P0 | 商业化红线文档 | 明确不卖数值碾压、不卖顶级成品 |
| P0 | 免费保险箱规则 | 默认 2 格，作为所有玩家基础能力 |
| P0 | 任务事件埋点 | 击杀、拾取、撤离至少能被记录 |
| P0 | 结算展示 | 结算界面能展示任务事件结果 |
| P1 | 新手任务 6 个 | 覆盖进图、击杀、拾取、保险箱、撤离、强化 |
| P1 | 任务奖励 | 任务完成后发金币或强化石 |
| P1 | 日常任务占位 | 有 3-5 个日常任务配置草案 |
| P1 | 月卡/通行证草案 | 只写规则，不接付费 |
| P2 | 赛季结构草案 | 等核心闭环稳定后再做 |
| P3 | 行会结构草案 | 不进入第一阶段 |

## 8. 开工顺序

1. 写商业化红线和免费保险箱规则。
2. 接事件计数：击杀、拾取、撤离。
3. 在结算界面展示事件结果。
4. 核心闭环稳定后，再接任务奖励、保险箱任务和强化任务。
5. 等核心留存成立后，再规划月卡、通行证和赛季任务。

## 9. 验收标准

- 新玩家按任务走，能自然完成第一局核心流程。
- 任务不会要求玩家离开核心玩法去做杂事。
- 奖励能帮助下一局体验，但不会替代掉落价值。
- 商业化规划不会直接提高 PVP 伤害或出售顶级装备。
- 行会和赛季不会占用第一阶段开发资源。

## 10. 主要风险

- 商业化过早接入，污染核心玩法验证。
- 保险箱被玩家理解为“付费不掉落”，所以第一阶段只验证免费基础能力。
- 任务太多打断刷宝节奏，首版任务必须短、顺路、少弹窗。
- 太早做行会导致资源分散。
- 赛季奖励如果给强数值，会破坏刷宝和 PVP 公平。
