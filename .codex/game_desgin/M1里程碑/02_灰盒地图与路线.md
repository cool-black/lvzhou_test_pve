# 02 灰盒地图与路线

## 1. 目标

做一张 10-12 分钟可跑通的废土地宫灰盒地图，让玩家明确知道哪里刷怪、哪里有精英、哪里撤离。

## 2. 区域结构

| 区域 | 功能 | 内容 | 程序需求 |
| --- | --- | --- | --- |
| 出生点 | 开局安全区 | 默认武器、弹药、药品提示 | 玩家出生坐标、短暂安全范围 |
| 普通区 A | 首次战斗 | 行尸 6-10 只 | 1 个刷怪组，靠近出生点 |
| 普通区 B | 掩体压力 | 枪兵 4-6 只，行尸 4-6 只 | 掩体物、远程怪刷新点 |
| 精英区 | 中段目标 | 1 个精英怪 + 普通怪少量 | 精英刷新点、区域提示 |
| Boss 占位区 | 高价值目标 | 1 个强化精英或 Boss 占位怪 | 高价值目标刷新点 |
| 固定撤离点 | 单局出口 | 8 秒撤离倒计时 | 触发器、倒计时 UI、结算回调 |

## 3. 路线节奏

| 时间 | 玩家事件 | 地图要求 |
| --- | --- | --- |
| 0:00-1:00 | 出生并看到第一条路线 | 出生点可直接看见普通区入口 |
| 1:00-3:00 | 第一波普通怪 | 怪物密度低，保证新手能打完 |
| 3:00-5:00 | 掉落和补给 | 地面掉落可见，路线不分叉太多 |
| 5:00-8:00 | 是否深入精英区 | 精英区入口需要视觉提示 |
| 8:00-10:00 | 精英战斗 | 有掩体和回旋空间 |
| 10:00-12:00 | 撤离或挑战 Boss 占位 | 撤离点路线清晰，Boss 区是可选贪婪路线 |

## 4. 灰盒摆放规则

- 出生点到第一波怪距离：15-30 秒移动时间。
- 普通区之间必须有基础掩体，避免枪兵纯数值惩罚。
- 精英区必须有至少两条绕行/拉扯路径。
- 固定撤离点不能贴在 Boss 占位区旁边，避免无脑打完即撤。
- M1 不做撤离点蹲守对抗，因此撤离点优先放在路线回收处。

## 5. 地图标记

| 标记 | 表现 | 触发 |
| --- | --- | --- |
| 主路线提示 | 光源、箭头、地面引导均可 | 开局默认可见 |
| 精英区提示 | 区域名、警示音或 UI 文本 | 玩家进入精英区附近 |
| 撤离点提示 | 屏幕标记 + 区域光柱 | 开局可见 |
| Boss 占位提示 | 高价值目标提示 | 精英死亡后或进入 Boss 区 |

## 6. 可调参数

| 参数 | M1 默认值 |
| --- | --- |
| 普通怪总数 | 20-30 只 |
| 精英数量 | 1 只 |
| Boss 占位数量 | 0-1 只 |
| 固定撤离点数量 | 1 个 |
| 单局目标时长 | 10-12 分钟 |

## 7. 验收标准

- 玩家进入地图 1 分钟内看到敌人。
- 玩家不看策划说明也能找到固定撤离点。
- 8-10 分钟内能自然遇到精英或高价值目标。
- 地图能支持行尸追击、枪兵掩体对射、精英拉扯。
- 连续 10 局没有怪物刷在不可达位置。

## 8. 不做范围

- 随机地图。
- 随机撤离点。
- Boss 撤离点。
- PVP 路线博弈。
- 完整美术、灯光、氛围包装。
