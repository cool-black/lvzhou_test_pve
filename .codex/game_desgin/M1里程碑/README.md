# M1 里程碑总览

> 目标：把“PVE 爆装撤离”做成可连续跑 10 局的灰盒闭环。

## 1. M1 唯一验收问题

玩家是否愿意反复完成这条链路：

```text
进入废土地宫
  -> 射击清怪
  -> 获得未结算掉落
  -> 击杀 1 个精英 / Boss 占位目标
  -> 选择保险箱封存或继续推进
  -> 固定撤离点撤离，或死亡失败
  -> 结算展示带出 / 损失 / 保险箱保留
  -> 消耗金币和强化石强化武器
  -> 下一局清怪效率提升
```

## 3. M1 不做

- 完整 Boss 三阶段。
- Boss 撤离点。
- 真实玩家 PVP 和红名。
- 随机撤离点。
- 完整职业、技能树、词条洗练。
- 交易、月卡、通行证、付费扩容。
- 行会、沙城战、世界 Boss。

## 4. 通过标准

| 指标 | M1 目标 |
| --- | --- |
| 首次战斗 | 进入地图 1 分钟内看到敌人，3 分钟内完成第一波 |
| 有效掉落 | 单局 3-5 次 |
| 精英目标 | 8-10 分钟内遇到 |
| 撤离理解 | 玩家知道撤离后物资入库 |
| 死亡理解 | 玩家知道死亡损失与保险箱保留 |
| 成长反馈 | +3 后普通区清怪时间下降 20% 以上 |
| 稳定性 | 连续 10 局无重复结算、物品丢失、撤离失效 |
