# 04 掉落背包经济

## 1. 目标

建立最小收益链：怪物死亡生成掉落，玩家拾取为未结算物资，撤离后入库，死亡后按规则损失，局后消耗材料强化。

## 2. M1 物品类型

| 类型 | 用途 | 是否未结算 | 是否可保险 |
| --- | --- | --- | --- |
| 金币 | 购买/强化基础消耗 | 是 | M1 不占保险箱，死亡损失部分 |
| 基础强化石 | +1 到 +3 强化 | 是 | 可 |
| 高级强化石 | +4 到 +5 强化 | 是 | 可 |
| 绿/蓝测试装备 | 掉落反馈和成长替换 | 是 | 可选 |
| 紫色材料 | 精英/Boss 占位奖励 | 是 | 可 |
| Boss 材料 | 高价值目标奖励 | 是 | M1 不建议可保险 |

## 3. 掉落表草案

| 来源 | 白 | 绿 | 蓝 | 紫 | 橙 |
| --- | --- | --- | --- | --- | --- |
| 普通怪 | 60% | 30% | 9% | 1% | 0% |
| 枪兵/强化怪 | 30% | 40% | 25% | 5% | 0% |
| 精英怪 | 10% | 30% | 45% | 14% | 1% |
| Boss 占位 | 0% | 10% | 45% | 35% | 10% 图纸碎片/材料，不掉完整橙装 |

## 4. 单局产出预算

| 项目 | 起始目标 |
| --- | --- |
| 普通怪数量 | 单局 20-30 只 |
| 精英数量 | 单局 1 只 |
| Boss 占位目标 | 0-1 只 |
| 有效掉落次数 | 单局 3-5 次 |
| 普通撤离带出 | 金币、基础强化石、1-2 件绿/蓝物资 |
| 精英撤离带出 | 额外蓝装或紫色材料机会 |
| 死亡失败 | 保险箱保留，普通材料损失 50%，蓝色以上未保护物资先全部损失 |

## 5. 数据结构草案

```lua
RunLootState = {
    [PlayerKey] = {
        UnsettledItems = {
            {
                InstanceID = 10001,
                ItemID = 8310001,
                Count = 1,
                Quality = 2,
                Source = "Monster_Normal",
                Protected = false
            }
        },
        SafeBoxItems = {},
        ExtractedItems = {},
        LostItems = {}
    }
}
```

## 6. 掉落流程

1. 怪物死亡触发 `OnMonsterDeath`。
2. 服务端按 `DropTableID` 计算掉落。
3. 生成可拾取物或直接创建拾取提示。
4. 玩家拾取后写入 `RunLootState.UnsettledItems`。
5. UI 标记为“未结算”。
6. 撤离成功时转入仓库/已结算列表。
7. 死亡失败时按损失规则处理。

## 7. 强化消耗

| 强化等级 | 消耗 | 效果 | 失败规则 |
| --- | --- | --- | --- |
| +1 到 +3 | 金币 + 基础强化石 | 每级约 8%-10% 伤害提升 | 100% 成功 |
| +4 到 +5 | 金币 + 高级强化石 | 每级约 10%-12% 伤害提升 | M1 可先 100% 成功 |
| +6 以后 | 不做 | 后续版本 | 不做 |

## 8. 程序接口需求

| 接口 | 用途 |
| --- | --- |
| `RollDrop(DropTableID)` | 计算掉落物 |
| `AddUnsettledItem(PlayerKey, Item)` | 拾取进入未结算收益 |
| `MoveToSafeBox(PlayerKey, InstanceID)` | 放入保险箱 |
| `SettleExtractedItems(PlayerKey)` | 撤离成功入库 |
| `SettleLostItems(PlayerKey)` | 死亡失败损失 |
| `UpgradeWeapon(PlayerKey, WeaponID)` | 消耗材料强化 |

## 9. 验收标准

- 普通玩家单局获得 3-5 次有效掉落反馈。
- 精英收益明显高于普通怪。
- 撤离成功后未结算物资能转为已结算。
- 死亡失败后保险箱保留，未保护物资按规则损失。
- 3 局内至少能完成 1-2 次强化。

## 10. 不做范围

- 交易。
- 复杂洗练。
- 未鉴定装备开奖。
- 完整仓库整理。
- 真实付费材料投放。
