# 03 怪物战斗系统

## 1. 目标

用最小怪物组合验证射击刷怪是否有乐趣：近战压迫、远程掩体、精英机制、Boss 占位目标。

## 2. M1 怪物清单

| 怪物 | 类型 | 行为 | 掉落定位 | M1 必做 |
| --- | --- | --- | --- | --- |
| 污染行尸 | 普通近战 | 发现玩家后追击，近身攻击 | 金币、白绿装、弹药 | 是 |
| 废土枪兵 | 普通远程 | 中距离射击，低频换位 | 弹药、材料、绿装 | 是 |
| 重甲矿奴 | 精英 | 高血量，正面减伤或背后增伤 | 蓝装、强化石、紫色材料机会 | 二选一 |
| 地宫祭司 | 精英 | 召唤小怪或范围伤害 | 蓝装、强化石、紫色材料机会 | 二选一 |
| Boss 占位目标 | 高价值目标 | 高血量精英，血量分段提示 | Boss 材料、紫色材料机会 | 可用精英替代 |

## 3. 战斗参数草案

| 单位      | TTK / 时长目标             | 战斗要求                  |
| ------- | ---------------------- | --------------------- |
| 行尸      | +0 步枪 1.0-1.5 秒        | 成群出现，提供清怪爽感           |
| 枪兵      | +0 步枪 2.0-3.0 秒        | 迫使玩家找掩体或优先点杀          |
| 精英      | 单人 60-90 秒，小队 30-60 秒  | 需要拉扯、转火或打机制           |
| Boss 占位 | 单人 90-150 秒，小队 60-90 秒 | 作为贪婪路线目标，不做完整 Boss 表现 |

## 4. 怪物状态

| 状态 | 含义 | 事件 |
| --- | --- | --- |
| `Idle` | 未发现玩家 | 玩家进入仇恨范围 |
| `Alert` | 发现玩家，准备攻击 | 转入追击或射击 |
| `Chase` | 行尸追击 | 进入攻击距离 |
| `Shoot` | 枪兵射击 | 射击间隔、换位、受击 |
| `Skill` | 精英/Boss 占位释放机制 | 冷却结束或血量阶段触发 |
| `Dead` | 死亡 | 通知掉落和任务计数 |

## 5. 伤害公式草案

```text
最终伤害 = 武器基础伤害
  * 强化倍率
  * 怪物类型修正
  * 弱点/机制修正
```

M1 只需要实现 `武器基础伤害`、`强化倍率`、`怪物血量`、`精英机制修正`。PVP 目标类型判断预留接口即可。

## 6. 程序接口需求

| 接口                                                  | 用途                |
| --------------------------------------------------- | ----------------- |
| `SpawnMonster(GroupID)`                             | 按区域刷怪组生成怪物        |
| `OnMonsterDeath(MonsterID, KillerKey, MonsterType)` | 通知掉落、任务、波次推进      |
| `GetMonsterConfig(MonsterID)`                       | 读取血量、攻击、速度、掉落表 ID |
| `ApplyDamage(Target, DamageContext)`                | 计算伤害和弱点/强化倍率      |
| `OnEliteKilled(PlayerKey)`                          | 记录精英击杀事件          |

## 7. 可调参数

| 参数 | M1 默认方向 |
| --- | --- |
| 行尸数量 | 第一波 6-10 只，全局 12-18 只 |
| 枪兵数量 | 第一局 6-10 只 |
| 精英数量 | 1 只 |
| Boss 占位数量 | 0-1 只 |
| 精英奖励倍率 | 普通怪 3-5 倍价值 |

## 8. 验收标准

- 行尸能追击、攻击、死亡并触发掉落。
- 枪兵能制造掩体压力，但不让玩家被瞬间击倒。
- 精英怪比普通怪明显更难，也明显更值得打。
- Boss 占位目标死亡能掉 Boss 材料。
- +3 强化后普通区清怪时间下降 20% 以上。

## 9. 不做范围

- 自爆怪。
- 完整 Boss 三阶段。
- 复杂弱点碰撞。
- 技能树和职业技能。
- PVP 伤害平衡。
