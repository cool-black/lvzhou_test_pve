# 《枪火玛法：废土地宫》游戏设计文档 (GDD)

> 版本：V0.2  
> 日期：2026-04-26  
> 项目定位：基于和平精英 / 绿洲启元 UGC 的 PVE 刷宝射击玩法  
> 核心优先级：PVE 刷宝 > PVP 撤离争夺 > 行会沙城战

---

## 一、项目概述

### 1.0 V0.2 设计收敛

本版本根据制作人评审做出以下收敛：

- M1 只验证“PVE 爆装撤离”闭环，不把完整 Boss、PVP、行会、世界 Boss、完整红名和复杂赛季作为 MVP 内容。
- PVP 定位为高级收益区的风险和争夺压力，不作为首版主玩法宣传点。
- 装备成长在 PVE 中要明显，在 PVP 中要克制。建议目标为：PVE 中装备影响 60%-70%，操作影响 30%-40%；PVP 中操作影响 70%-80%，装备影响 20%-30%。
- 怪物必须有射击互动，不做纯血厚木桩。M1 保底验证冲锋、远程和 1 个精英机制；自爆、护甲弱点、召唤压迫在 M2 前补齐。
- 保险箱是风险缓冲和商业化点，M1 免费容量固定为 2 格；付费只能降低损失，不直接增加战斗力。
- 现阶段制作拆分见 `Systems/README.md`，每个系统的 MVP 任务、验证标准和风险单独维护。

### 1.1 一句话概念

《枪火玛法：废土地宫》是一款以和平精英射击手感为基础、融合传奇式刷怪爆装与三角洲式搜打撤风险收益的房间制 PvPvE 刷宝射击游戏。

玩家组队进入危险地宫，击杀怪物、精英和 Boss 获取装备、材料与稀有图纸，在其他玩家小队的威胁下选择继续贪、封存战利品或撤离结算，最终通过装备成长挑战更高阶地图，并在后期参与行会据点与沙城争夺。

### 1.2 设计目标

- 做出“打怪会爆、爆了想撤、撤了还想再进”的循环。
- 保留和平精英的枪械射击、移动、掩体和多人对抗优势。
- 用传奇式装备品质、Boss 争夺、地图层级和长期养成制造留存。
- 用搜打撤结构强化 PVP 的紧张感，但不让 PVP 压过 PVE 主体验。
- 通过保险箱系统提供合理商业化：付费降低损失，不直接购买战斗胜利。

### 1.3 目标用户

- 喜欢和平精英射击操作，但希望有更强成长和刷宝目标的玩家。
- 喜欢传奇、暗黑、刷装备、打 Boss、爆稀有道具的玩家。
- 喜欢三角洲行动、暗区突围等撤离玩法，但希望死亡惩罚更轻的玩家。
- 适合 2-4 人固定小队，也支持单人进入低难度地图。

### 1.4 玩法基调

- 主体验：爽快 PVE 刷怪、打 Boss、爆装。
- 中层压力：高级资源区存在其他玩家小队，形成争夺和撤离风险。
- 长线目标：装备成型、技能构筑、行会据点、沙城战。
- 气质：末世废土 + 东方传奇地宫 + 军事科幻装备。

## 二、核心玩法

### 2.1 核心循环

```text
准备装备
  -> 进入地图
  -> 清怪推进 / 搜索物资
  -> 发现精英怪或 Boss
  -> 战斗并获得未结算战利品
  -> 选择封存、继续深入或撤离
  -> 成功撤离后入库
  -> 强化装备 / 解锁技能 / 提升战力
  -> 挑战更高难度地图
```

### 2.2 单局流程

1. 玩家在安全区选择地图、难度、携带装备和消耗品。
2. 进入地宫后，地图内刷新普通怪、精英怪、物资箱和随机事件。
3. 玩家通过刷怪和探索获得未结算物资。
4. 中后段刷新区域 Boss 或事件 Boss，吸引多个小队争夺。
5. 高价值战利品需要玩家撤离后才会真正进入仓库。
6. 玩家可使用保险箱保护少量稀有物资。
7. 撤离成功后结算经验、金币、材料、装备和战斗评价。

### 2.3 首版单局时长

- 完整体验目标时长：15-20 分钟。
- M1 灰盒验证可先压缩到 10-12 分钟，优先确认闭环和成长反馈。
- 前 5 分钟：清怪、搜物资、建立装备收益。
- 中 5-10 分钟：精英怪、资源争夺、路线选择。
- 后 5 分钟：Boss、撤离点冲突、风险决策。

### 2.4 体验关键词

- 刷怪爽感：怪群密度适中，击杀反馈明确。
- 爆装期待：掉落光柱、品质颜色、稀有音效、全队提示。
- 撤离紧张：背包越值钱，越想活着离开。
- PVP 克制：遇到人不是必须打，绕路、谈判、伏击、抢尾刀都成立。
- 成长明确：每局结束都能带来战力或资源积累。

## 三、模式结构

### 3.1 模式分层

| 模式 | 定位 | PVP 强度 | 主要收益 |
| --- | --- | --- | --- |
| 新手矿区 | 教学与低压刷宝 | 无 PVP | 基础装备、金币、弹药 |
| 废土外环 | 标准 PVE 刷宝 | 弱 PVP / 红名惩罚 | 蓝紫装备、强化材料 |
| 地宫禁区 | 搜打撤核心 | 中高 PVP | 紫橙装备、图纸、Boss 材料 |
| 深渊核心 | 高风险终局地图 | 自由 PVP | 红装材料、套装部件 |
| 沙城战 | 行会赛季玩法 | 阵营 PVP | 行会资源、据点权益 |

### 3.2 M1 MVP 范围

M1 只做一个完整闭环，不追求大世界，也不追求完整传奇 MMO 形态：

- 1 个安全出生点。
- 1 张废土地宫灰盒地图。
- 2 类普通怪：污染行尸、废土枪兵。
- 1 类精英怪：重甲矿奴或地宫祭司二选一。
- 1 个 Boss 占位目标：可用强化精英代替，死亡后掉 Boss 材料。
- 1 套基础装备品质。
- 1 套固定撤离点与结算规则。
- 1 个免费 2 格保险箱系统。
- 1 套基础强化系统。

M1 暂缓：

- 完整 Boss 三阶段。
- Boss 撤离点。
- 真实玩家 PVP 和 Boss 区争夺。
- 完整行会系统。
- 世界 Boss。
- 大规模沙城战。
- 复杂交易系统。
- 完整红名生态。
- 多地图赛季内容。

M1 的唯一验收问题是：玩家是否愿意反复进行“进图刷怪、爆出东西、封存或撤离、结算强化、再进一局”。

## 四、地图设计

### 4.1 地图主题：废土地宫

废土地宫是旧军事基地和远古地宫融合后的污染区域。上层是废弃矿区、弹药仓和坍塌通道，下层是能量祭坛、Boss 巢穴和高价值物资区。

### 4.2 区域结构

| 区域 | 功能 | 风险 |
| --- | --- | --- |
| 安全入口 | 玩家出生、基础补给 | 无 |
| 废弃矿道 | 普通怪密集，适合刷基础材料 | 低 |
| 军械残库 | 物资箱较多，可能刷新精英怪 | 中 |
| 污染裂隙 | 精英怪和随机事件 | 中高 |
| 地宫祭坛 | Boss 区和高级战利品 | 高 |
| 撤离点 A | 固定撤离，位置明显 | 易被蹲守 |
| 撤离点 B | 随机开放，路线较远 | 中 |
| Boss 撤离点 | 击杀 Boss 后短时开放 | 高 |

### 4.3 路线设计

地图需要提供三种路线：

- 稳健路线：刷普通怪和低级物资，提前撤离。
- 贪婪路线：深入精英区，拿更多材料和紫装机会。
- 争夺路线：直奔 Boss 区，与其他玩家抢最高收益。

### 4.4 撤离点设计

- 固定撤离点：开局可见，随时可撤，但容易遭遇伏击。
- 随机撤离点：单局中段开放，降低固定点蹲守问题。
- Boss 撤离点：Boss 死亡后开启 90 秒，位置接近 Boss 区，适合高风险快速撤离。

## 五、战斗系统

### 5.1 基础战斗

沿用和平精英的枪械射击体验，包括：

- 主武器、副武器、投掷物。
- 掩体、走位、拉枪、换弹节奏。
- 小队协作、倒地救援、补给分配。

玩法新增 RPG 化战斗层：

- 怪物有护甲、弱点、抗性。
- Boss 有阶段技能和范围攻击。
- 装备词条影响伤害、暴击、吸血、换弹、弹匣、Boss 增伤等属性。

战斗平衡底线：

- PVE 允许装备成长带来明显效率差异，让刷装有价值。
- PVP 必须保留和平精英玩家熟悉的枪法、走位、掩体、信息和协作价值。
- PVP 中高阶装备不能形成不可反制的秒杀或碾压。
- 技能和词条在 PVP 中可使用单独倍率，避免 RPG 数值破坏射击公平感。

### 5.2 职业方向

首版不做强职业绑定，先用“战斗流派”表达职业感。

| 流派 | 推荐武器 | 特点 |
| --- | --- | --- |
| 突击者 | 步枪 / 冲锋枪 | 近中距离持续输出，适合清怪 |
| 狙猎者 | 狙击枪 / 精确射手步枪 | 点杀精英，标记 Boss 弱点 |
| 工兵 | 机枪 / 霰弹 / 道具 | 炮台、护盾、补给、控制 |

后续可扩展为正式职业：

- 枪斗士：高机动、高爆发。
- 弹药师：范围伤害、弹药补给。
- 机械师：炮塔、护盾、陷阱。
- 猎魔人：Boss 增伤、弱点标记、稀有追踪。

### 5.3 技能设计原则

- 技能服务于 PVE 清怪和 Boss 战，不做纯竞技碾压。
- PVP 中技能效果可衰减，避免技能秒人。
- 技能以冷却和资源消耗控制频率。
- 技能尽量复用和平精英已有表现和 UGC 技能编辑器能力。

## 六、怪物与 Boss

### 6.1 怪物分级

| 类型 | 作用 | 掉落 |
| --- | --- | --- |
| 普通怪 | 提供基础刷怪爽感 | 金币、弹药、白绿装、基础材料 |
| 强化怪 | 打断玩家节奏 | 蓝装、强化石、小概率紫装 |
| 精英怪 | 小目标点 | 紫装、技能碎片、图纸碎片 |
| 区域 Boss | 单局核心目标 | 橙装、套装部件、稀有材料 |
| 世界 Boss | 多队争夺目标 | 红装材料、行会资源、称号道具 |

### 6.2 首版怪物

| 名称 | 类型 | 行为 |
| --- | --- | --- |
| 污染行尸 | 普通近战怪 | 成群冲锋，血量低 |
| 废土枪兵 | 普通远程怪 | 掩体射击，压制玩家 |
| 爆裂虫 | 自爆怪 | 接近后爆炸，迫使玩家走位 |
| 重甲矿奴 | 精英怪 | 高护甲，弱点在背部能量罐 |
| 地宫祭司 | 精英怪 | 召唤小怪，释放范围毒雾 |
| 赤铁魔将 | 首版 Boss | 三阶段 Boss，近战冲锋、召唤、狂暴弹幕 |

首版怪物设计要求：

- 每类怪物必须迫使玩家做一种不同的射击决策。
- 冲锋怪提供压迫，远程怪迫使玩家找掩体，自爆怪迫使玩家走位。
- 精英怪必须提供弱点或破甲机制，让枪法和团队集火有价值。
- Boss 不只提高血量，必须用阶段变化制造节奏。

### 6.3 Boss 战设计：赤铁魔将

阶段一：守门者  
Boss 使用重锤近战和短距离冲锋，教学玩家躲避红圈。

阶段二：召唤者  
Boss 召唤污染行尸和废土枪兵，队伍需要分工清怪和输出。

阶段三：狂暴者  
Boss 血量低于 30% 后提升移动速度，开启范围火雨和护甲破坏攻击。

核心掉落：

- 赤铁核心。
- 橙色武器图纸。
- Boss 专属词条材料。
- 小概率掉落“沙城令碎片”。

## 七、装备与掉落

### 7.1 装备品质

| 品质 | 颜色 | 定位 |
| --- | --- | --- |
| 普通 | 白 | 过渡装备 |
| 精良 | 绿 | 基础成长 |
| 稀有 | 蓝 | 有 1 条词条 |
| 史诗 | 紫 | 有 2 条词条 |
| 传说 | 橙 | 有 3 条词条或特殊效果 |
| 神话 | 红 | 赛季终局追求 |

### 7.2 装备类型

- 枪械：步枪、冲锋枪、霰弹枪、狙击枪、机枪。
- 防具：头盔、护甲、战术背包。
- 饰品：徽章、核心、护符。
- 消耗品：药剂、弹药包、封存芯片、强化材料。
- 图纸：高级枪械图纸、技能模块图纸、套装部件图纸。

### 7.3 枪械词条

| 词条 | 效果 |
| --- | --- |
| 猎魔 | 对怪物伤害提升 |
| 破甲 | 无视部分护甲 |
| 嗜血 | 击杀怪物回复生命 |
| 连射 | 连续命中提升射速 |
| 稳定 | 降低后坐力 |
| 快填 | 提升换弹速度 |
| 首领杀手 | 对 Boss 伤害提升 |
| 幸运 | 提升稀有掉落权重 |

### 7.4 掉落归属

首版建议采用“小队归属 + 个人可见”混合规则：

- 普通掉落：个人可见，避免队友抢基础收益。
- 精英掉落：小队共享，队内分配。
- Boss 掉落：生成 Boss 战利品箱。
- Boss 战利品箱：按伤害贡献解锁开启权限，但物品必须撤离后才真正入库。

### 7.5 未结算物资

地图内获得的高价值物资默认是“未结算”状态：

- 撤离成功：进入仓库。
- 死亡失败：按规则掉落或损失。
- 放入保险箱：即使死亡也保留。

## 八、PVP 与撤离争夺系统

### 8.1 PVP 定位

PVP 是资源争夺压力，不是主要杀人目标。玩家进入地图的第一动机是刷怪和打宝，PVP 负责制造风险、博弈和高潮。

首版 PVP 收敛：

- 首版优先只开放 Boss 区或禁区 PVP，不做全图自由 PK。
- 必须保留可避战路线、随机撤离点和提前撤离选择。
- PVP 失败的损失应集中在未结算物资，不掉已穿戴核心装备。
- PVP 宣传语应强调“高收益区会遇到其他小队”，避免把玩法包装成纯竞技。

### 8.2 PVP 分区规则

| 区域 | PVP 规则 |
| --- | --- |
| 新手矿区 | 禁止 PVP |
| 普通刷宝区 | 可攻击，但主动击杀会红名 |
| Boss 争夺区 | 允许 PVP，击杀不红名或低惩罚 |
| 地宫禁区 | 自由 PVP |
| 安全区 | 禁止攻击 |

### 8.3 红名机制

主动攻击并击杀非红名玩家会增加红名值。

红名惩罚：

- 死亡时掉落更多未结算物资。
- 保险箱容量临时降低。
- 进入部分安全功能时受到限制。
- 高红名玩家在地图上短暂暴露位置。

设计目的：允许 PVP，但抑制无成本屠杀。

### 8.4 搜打撤规则

玩家携带装备进入地图，获得未结算物资后必须撤离才可入库。

死亡规则：

- 已穿戴装备不掉落，降低挫败感。
- 背包内未结算材料掉落 50%-70%。
- 未封存的稀有装备有概率掉落或损毁。
- 保险箱内物品完全保留。

### 8.5 撤离博弈

玩家在地图中需要不断做选择：

- 继续深入打 Boss，还是先撤？
- 背包满了，保哪个物资？
- 队友倒地，要救人还是带货撤？
- 听到其他小队枪声，要绕开、伏击还是抢 Boss？

## 九、保险箱系统

### 9.1 系统定位

保险箱是本项目的重要风险缓冲和商业化系统。玩家可以把少量稀有物资放入保险箱，即使本局死亡或撤离失败，保险箱内物品也会保留。

### 9.2 基础规则

- 每名玩家默认拥有基础保险箱。
- 保险箱容量有限，首版建议免费容量为 2 格。
- 放入保险箱需要 3-5 秒封存动作。
- 封存过程中受到伤害会被打断。
- 保险箱物品在本局结束后进入仓库。

### 9.3 可放入物品

可放入：

- 稀有材料。
- 图纸碎片。
- 强化石。
- 宝石。
- 小型高价值道具。

限制放入：

- 完整红装。
- Boss 核心战利品。
- 行会战旗、据点核心等目标物。
- 特定活动道具。

### 9.4 商业化扩展

| 类型 | 内容 | 原则 |
| --- | --- | --- |
| 免费基础 | 2 格保险箱 | 所有人都能体验机制 |
| 月卡权益 | 增至 3-4 格 | 降低损失，不加战斗力 |
| 通行证权益 | 赛季保险箱皮肤 / 临时扩容 | 提供长期价值 |
| 消耗道具 | 高级封存芯片，本局额外保护 1 件 | 控制投放，避免经济失衡 |
| 活动奖励 | 限时保险券 | 促进活跃 |

### 9.5 反失衡规则

- 保险箱不能保护所有最高价值目标物。
- 红名状态降低保险箱容量或禁用额外扩容。
- 高级地图可设置保险箱使用次数上限。
- 保险箱扩容只减少损失，不直接提升输出、防御或掉率。

## 十、成长系统

### 10.1 成长维度

- 装备品质。
- 装备强化等级。
- 枪械词条。
- 技能模块。
- 地图准入等级。
- 行会科技。

### 10.2 强化系统

强化材料来自刷怪、精英和 Boss。

强化规则建议：

- +1 到 +5 成功率高，不失败降级。
- +6 到 +10 需要高级材料，失败不碎装但消耗材料。
- 橙装以上可洗练词条。
- 红装需要 Boss 材料和赛季材料合成。

### 10.3 技能模块

技能通过模块解锁和升级：

- 主动技能：护盾、炮塔、爆破、治疗、标记。
- 被动技能：怪物增伤、暴击、移速、换弹、掉落加成。
- 小队技能：复活加速、补给增强、Boss 弱点共享。

## 十一、经济系统

### 11.1 货币

| 货币 | 来源 | 用途 |
| --- | --- | --- |
| 金币 | 普通刷怪、任务 | 购买基础物资、修理、低级强化 |
| 晶核 | 精英怪、Boss | 高级强化、技能模块 |
| 沙城令碎片 | Boss、行会活动 | 行会科技、沙城战报名 |
| 点券 / 商业货币 | 付费 | 外观、月卡、通行证、保险箱权益 |

### 11.2 资源消耗口

- 装备强化。
- 词条洗练。
- 技能升级。
- 地图门票。
- 行会建设。
- 沙城战备。

### 11.3 经济原则

- 核心装备必须通过玩法获得。
- 付费提供效率、保护、外观和便利。
- 高价值材料需要持续消耗，避免经济快速膨胀。
- 赛季制重置部分排行和行会权益，但保留玩家基础收藏。

## 十二、任务与赛季

### 12.1 日常目标

- 完成 3 次撤离。
- 击杀 50 只怪物。
- 击杀 3 只精英怪。
- 带出 5 件蓝色以上物资。
- 使用保险箱封存 1 件稀有物资。

### 12.2 周常目标

- 击杀区域 Boss。
- 完成高难地宫撤离。
- 参与行会物资捐献。
- 完成小队协作任务。

### 12.3 赛季目标

- 收集赛季套装。
- 解锁沙城战资格。
- 击杀世界 Boss。
- 行会占领据点。
- 达成撤离大师、Boss 猎人、地宫富豪等称号。

## 十三、行会与沙城战

### 13.1 行会定位

行会是中后期长期目标，不是首版 MVP 核心。现阶段只保留为后续方向，不进入首版开发范围。行会提供组织、资源消耗、荣誉和大型 PVP 目标。

### 13.2 行会功能

- 行会成员列表。
- 行会捐献。
- 行会科技。
- 行会 Boss。
- 行会仓库。
- 沙城战报名。

### 13.3 沙城战规则概念

每周固定时间开启沙城战，多行会争夺核心据点。

胜利条件：

- 占领核心旗点达到指定时间。
- 或在时间结束时积分最高。

战场目标：

- 城门。
- 复活点。
- 补给车。
- 炮台。
- 中央核心。

占领奖励：

- 行会专属 Boss。
- 税收或资源分成。
- 专属商店。
- 行会称号和外观。

## 十四、商业化设计

### 14.1 商业化原则

- 不直接出售数值碾压。
- 不出售最高阶装备成品。
- 付费重点是损失保护、效率、外观、赛季目标和便利。
- 免费玩家必须能完整体验刷宝、撤离、强化和 Boss 争夺。

### 14.2 付费点

| 付费点 | 内容 |
| --- | --- |
| 月卡 | 保险箱扩容、每日金币、每日封存券 |
| 通行证 | 赛季外观、保险箱皮肤、材料返还券、称号 |
| 保险箱扩容 | 增加 1-2 格保护空间 |
| 封存芯片 | 单局额外保护 1 件指定物资 |
| 外观 | 枪械皮肤、背包外观、撤离特效、称号 |
| 便利 | 仓库扩容、预设装备方案、快速整理 |

### 14.3 风险控制

- 保险箱扩容有上限。
- 高级封存道具限制每日使用次数。
- 红名削弱保险箱收益。
- Boss 核心目标物不能被完全保险保护。
- 所有付费便利不得直接提升 PVP 伤害。

## 十六、首版开发里程碑

### Phase 1：核心玩法验证

目标：验证刷怪、掉落、撤离、保险箱闭环。

内容：

- 废土地宫基础地图。
- 普通怪和精英怪刷新。
- 基础掉落表。
- 背包内未结算物资。
- 固定撤离点。
- 基础保险箱。

验收标准：

- 玩家能完整打一局并撤离。
- 死亡能触发损失和保险箱保护。
- 掉落品质有明确感知。

### Phase 2：Boss 与 PVP 争夺

目标：加入单局高潮和玩家冲突。

内容：

- 赤铁魔将 Boss。
- Boss 战利品箱。
- Boss 撤离点。
- PVP 分区。
- 红名机制。

验收标准：

- Boss 能吸引玩家争夺。
- PVP 产生风险但不破坏 PVE 主体验。

### Phase 3：成长与经济

目标：让玩家有多局追求。

内容：

- 装备强化。
- 词条洗练。
- 技能模块。
- 日常任务。
- 基础商店。

验收标准：

- 玩家 5 局后能感到战力成长。
- 材料有稳定消耗口。

### Phase 4：商业化与赛季

目标：加入长期留存和付费结构。

内容：

- 月卡。
- 通行证。
- 保险箱扩容。
- 外观奖励。
- 赛季任务。

验收标准：

- 付费点不破坏战斗公平。
- 免费玩家仍能完成核心循环。

### Phase 5：行会与沙城战

目标：建立终局社交目标。

内容：

- 行会系统。
- 行会 Boss。
- 据点争夺。
- 沙城战。
- 行会商店。

验收标准：

- 行会有持续资源需求。
- 沙城战能形成每周核心事件。

## 十七、关键风险与对策

| 风险            | 表现       | 对策                         |
| ------------- | -------- | -------------------------- |
| PVP 劝退 PVE 玩家 | 新手被反复击杀  | 新手区禁 PVP，红名惩罚，高级区才高收益      |
| 保险箱变成强付费      | 不付费就不敢进图 | 免费给基础保险箱，扩容有上限             |
| 掉落过快膨胀        | 玩家很快毕业   | 强化、洗练、行会科技做消耗口             |
| Boss 被强队垄断    | 普通玩家无体验  | 多 Boss 刷新、伤害贡献、随机撤离点       |
| 死亡惩罚过重        | 玩家不愿冒险   | 穿戴装备不掉，主要损失未结算物资           |
| 系统过大难落地       | 首版做不完    | MVP 只做 1 图、1 Boss、基础保险箱和撤离 |

## 十八、首版数值草案

### 18.1 单局收益目标

| 玩家表现 | 预期收益 |
| --- | --- |
| 早撤 | 少量金币、基础材料、白绿装 |

| 死亡失败 | 保留保险箱物品，损失多数未结算收益 |

### 18.2 掉落概率初稿

| 来源 | 白 | 绿 | 蓝 | 紫 | 橙 |
| --- | --- | --- | --- | --- | --- |
| 普通怪 | 60% | 30% | 9% | 1% | 0% |
| 强化怪 | 30% | 40% | 25% | 5% | 0% |
| 精英怪 | 10% | 30% | 45% | 14% | 1% |
| 区域 Boss | 0% | 10% | 45% | 35% | 10% |

注：概率为首版手感草案，实际需根据单局怪物数量、玩家撤离率和经济消耗调整。

### 18.3 M1 单局产出预算草案

以下不是最终平衡表，而是 M1 跑局和调参的起始预算。所有数值必须结合撤离率、死亡率和 10 局测试记录调整。

| 项目 | M1 起始目标 |
| --- | --- |
| 单局普通怪数量 | 20-30 只 |
| 单局精英数量 | 1 只 |
| Boss 占位目标 | 0-1 只，掉 Boss 材料，不直接掉完整橙装 |
| 普通玩家有效掉落 | 3-5 次 |

| 精英撤离带出 | 额外蓝装或紫色材料机会 |
| Boss 占位撤离带出 | Boss 材料、紫色材料机会、橙色图纸碎片小概率 |
| 死亡失败 | 保险箱保留，普通材料损失 50%，蓝色以上未保护物资先全部损失 |
| 3 局成长目标 | 至少完成 1-2 次强化，并感到普通区清怪更快 |
